### 2. Expandir `client-config/README.md`

Anadir secciones:

```markdown
## Server entry shape

| Field | Description |
|---|---|
| `transport` | `"stdio"`. The Gateway speaks JSON-RPC over stdin/stdout. |
| `command` | Binary to invoke. Use `"node"` (Node 20+ required). |
| `args` | Array of arguments. Must include the path to `gateway/src/mcp_server.js`. |
| `env` | Map of env vars. See "Required env vars" below. |

## Required env vars

| Var | Required | Default | Notes |
|---|---|---|---|
| `AGENTS_WORKSPACE` | recommended | `<repo>/workspace` | Root for runtime artifacts. |
| `AGENTS_POLICIES_DIR` | recommended | `<repo>/policies` | Registries dir. |
| `AGENTS_STATE_DB` | optional | `<workspace>/state/state.db` | SQLite path. |
| `AGENTS_AUDIT_LOG` | optional | `<workspace>/audit/events.jsonl` | Audit JSONL. |
| `AGENTS_TMUX_PREFIX` | optional | `ag-` | tmux session prefix. |
| `AGENTS_REPO_ROOTS` | required for spawn | (empty) | Colon-separated cwd allowlist. |
| `AGENTS_APPROVAL_MAX_WAIT_MS` | optional | `60000` | Server cap on `approval.wait`. |
| `AGENTS_DRY_RUN` | optional | `0` | Set `1` for dry-run mode. |

## Out of scope: IDE/host specifics

Configuring Cursor, Antigravity IDE or any specific MCP host is **out of
scope** for this project. The example above is intentionally minimal and
host-agnostic. Adapting it to your client's syntax (e.g. an IDE's
`mcp_servers.json`, a CLI's `~/.config/...`, a custom harness) is the
operator's responsibility.

The project commits to:

- Keeping `agents-gateway` as the server name.
- Keeping `transport: stdio` and the env var contract.
- Maintaining the smoke checklist below.
```

### 3. Test

`tests/structure/test_generic_mcp_config.py`:

```python
import json
from pathlib import Path

CFG = Path(__file__).resolve().parents[2] / "client-config" / "mcp.json.example"
README = Path(__file__).resolve().parents[2] / "client-config" / "README.md"


def test_generic_config_is_valid_json():
    json.loads(CFG.read_text(encoding="utf-8"))


def test_generic_config_uses_gateway_entrypoint():
    data = json.loads(CFG.read_text(encoding="utf-8"))
    args = data["mcpServers"]["agents-gateway"]["args"]
    assert any("gateway/src/mcp_server.js" in a for a in args)


def test_generic_config_uses_stdio_transport():
    data = json.loads(CFG.read_text(encoding="utf-8"))
    assert data["mcpServers"]["agents-gateway"]["transport"] == "stdio"


def test_generic_config_has_no_secrets():
    text = CFG.read_text(encoding="utf-8") + "\n" + README.read_text(encoding="utf-8")
    for pat in ("sk-", "AKIA", "ghp_"):
        assert pat not in text


def test_generic_config_has_no_ide_specific_keys():
    text = CFG.read_text(encoding="utf-8")
    for forbidden in ("cursor", "Cursor", "antigravity", "Antigravity", ".mdc", ".cursor"):
        assert forbidden not in text
```
