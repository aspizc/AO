| Campo | Valor |

## ¿Por que existe?

`U/0/0` valida el happy path; este test materializa el threat model en una **suite adversarial**. Cada amenaza listada en `docs/threat-model.md` (TM-01 .. TM-11) debe tener al menos un test que **demuestra que el bypass falla**. Sin esta suite, el threat model es prosa.

Esta suite es **bloqueante** del MVP: si una amenaza no tiene test, o no se documenta TODO trazado, no se cierra el MVP.

## ¿Que hay que hacer?

`tests/e2e/bypass_regression.test.js` con un caso por amenaza, mas wiring a `scripts/ci.sh` y trazabilidad bidireccional con `docs/threat-model.md`.

## Pre-requisitos

- A/0/6 publicado (threat model con TM-ids estables).
- Helpers de `tests/e2e/helpers/gateway_harness.js` (de U/0/0).
- Adapters dry-run.

### 2. Suite

`tests/e2e/bypass_regression.test.js`:

```javascript
import { test } from "node:test";
import assert from "node:assert/strict";
import path from "node:path";
import { startHarness } from "./helpers/gateway_harness.js";

// threat: TM-01
test("prompt_injection_against_orchestrator_cannot_get_raw_restricted", async () => {
  const h = startHarness();
  try {
    const { orchestration, task, artifact } = h.services;
    const orch = orchestration.create({
      callerAgent: "claude-code", callerRole: "orchestrator", goal: "test"
    });
    const t = task.assign({
      traceId: orch.traceId,
      caller: { agent: "claude-code", role: "orchestrator" },
      target: { role: "restricted-coder", agent: "gemini-cli" },
      repo: "cvision",
      description: "x"
    });
    const raw = artifact.put({
      traceId: orch.traceId, taskId: t.taskId,
      kind: "raw_diff", classification: "restricted",
      producer: { agent: "gemini-cli", role: "restricted-coder" },
      bodyText: "secret=AKIAFAKE"
    });

    // Simulate prompt-injected orchestrator trying to read raw directly
    assert.throws(
      () => artifact.get({
        artifactId: raw.artifactId,
        requester: { agent: "claude-code", role: "orchestrator" }
      }),
      /denied/i
    );
  } finally { h.cleanup(); }
});

// threat: TM-04
test("cwd_outside_allowlist_is_rejected_before_spawn", async () => {
  const h = startHarness();
  try {
    const { orchestration, task, agent } = h.services;
    const orch = orchestration.create({ callerAgent: "claude-code", callerRole: "orchestrator", goal: "x" });
    const t = task.assign({
      traceId: orch.traceId,
      caller: { agent: "claude-code", role: "orchestrator" },
      target: { role: "restricted-coder", agent: "gemini-cli" },
      repo: "cvision", description: "x"
    });
    await assert.rejects(
      agent.spawn({
        agent: "gemini-cli", role: "restricted-coder", repo: "cvision",
        cwd: "/etc",
        traceId: orch.traceId, taskId: t.taskId
      }),
      /cwd_outside_allowlist|not allowed/i
    );
  } finally { h.cleanup(); }
});

// threat: TM-04 (symlink)
// threat: TM-05 (sanitizer failure)
// threat: TM-06 (approval replay)
// threat: TM-07 (cross-trace artifact)
// threat: TM-08 (cross-trace message)

// threat: TM-10 (mcp stdout pollution)
// threat: TM-11 (approval.wait cap)

// ... un test por amenaza, con comentario `// threat: TM-XX`
```

### 3. Trazabilidad bidireccional

- En cada test: comentario `// threat: TM-XX`.
- En `docs/threat-model.md`: cada amenaza apunta a `tests/e2e/bypass_regression.test.js#<case>` (campo `Tested by:`).

### 4. CI gate

`scripts/ci.sh` ya corre `tests/e2e/`. Verifica que el test corre y falla en regresion (haz un experimento local: invierte una assertion, confirma que CI falla, revierte).

### 5. Skips controlados

Si una amenaza no se puede testear hoy:

```javascript
test.skip("xyz_threat", () => { /* TODO(U/0/4): testable when V/0/X lands */ });
```

Y dejar entry en `docs/mvp-acceptance-checklist.md` con TODO trazado.

## Errores comunes

- ❌ Pasar el caso accidentalmente porque la API no implementa la accion. Falla expansivamente: el test debe ejercitar la API real y verificar el control.
- ❌ Omitir el comentario `// threat: TM-XX`. Rompe trazabilidad.
- ❌ Permitir merge con `skip` sin TODO.
