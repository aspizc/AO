## ¿Por que existe?

V4 §30 enumera criterios de aceptacion del MVP. Sin un mapa explicito a evidencia, "MVP listo" es subjetivo. Esta checklist forma el contrato cerrado: cada criterio apunta a un test ID, doc path o checklist manual.

## ¿Que hay que hacer?

Crear `docs/mvp-acceptance-checklist.md` con cada criterio V4 §30 + columna `Evidence`.

### 3. Test estructural

`tests/structure/test_acceptance_checklist.py`:

```python
import re
from pathlib import Path

DOC = Path(__file__).resolve().parents[2] / "docs" / "mvp-acceptance-checklist.md"


def test_checklist_exists():
    assert DOC.is_file()


def test_each_item_has_evidence():
    text = DOC.read_text(encoding="utf-8")
    rows = [r for r in text.splitlines() if re.match(r"\| \d+ \|", r)]
    assert rows, "no checklist rows found"
    for row in rows:
        cols = [c.strip() for c in row.strip("|").split("|")]
        criterion, evidence, status = cols[1], cols[2], cols[3]
        assert criterion, f"empty criterion: {row}"
        assert evidence and evidence.lower() != "tbd", f"missing evidence: {row}"
        assert status in ("[ ]", "[x]"), f"invalid status: {row}"
```
