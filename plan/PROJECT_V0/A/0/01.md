## ¿Por que esta tarea existe?

Antes de escribir codigo necesitamos: una **descripcion** del proyecto, un **`.gitignore`** que evite commitear `node_modules`, DBs y artefactos runtime, un **changelog** para trackear cambios por tarea y una decision explicita sobre **licencia** (no inventar una sin que el owner decida).

Sin esto, las tareas posteriores generan ruido en el git log y arrastran ficheros que no deberian estar versionados.

## ¿Que hay que hacer?

Crear `README.md` con quickstart, `.gitignore` con las exclusiones runtime de V4, `CHANGELOG.md` con seccion `## Unreleased` y, si no hay decision de licencia, dejar un placeholder en `docs/license-decision-needed.md` en lugar de inventarla.

### 6. Test estructural

Crear `tests/structure/test_repo_metadata.py`:

```python
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parents[2]


def test_readme_exists():
    assert (REPO_ROOT / "README.md").is_file()


def test_readme_mentions_v4_plan():
    text = (REPO_ROOT / "README.md").read_text(encoding="utf-8")
    assert "plan_proyecto_v4.md" in text


def test_gitignore_ignores_runtime_artifacts():
    text = (REPO_ROOT / ".gitignore").read_text(encoding="utf-8")
    for pattern in ("node_modules/", "*.db", ".env",
                    "workspace/state/*", "workspace/audit/*"):
        assert pattern in text, f"missing pattern: {pattern}"


def test_changelog_has_unreleased_section():
    text = (REPO_ROOT / "CHANGELOG.md").read_text(encoding="utf-8")
    assert "## Unreleased" in text
```
