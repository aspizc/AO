## ¿Por que esta tarea existe?

El operador necesita una CLI **fuera** del Gateway: para validar registries, consultar la policy, leer audit log y resolver approvals desde terminal **sin** depender de un IDE. Esa CLI es `agent-run`, escrita en Python con Typer.

Aqui dejamos solo el scaffold: comando `agent-run` que muestra `--help`, `--version` y subcomandos vacios `policy`, `audit`, `approve` que las tareas siguientes (B/0/5, D/0/3, E/0/0..2, Q/0/3) iran rellenando.

## ¿Que hay que hacer?

Crear `cli/pyproject.toml` con dependencia Typer/Rich/jsonschema/pytest, `cli/src/agents_cli/main.py` con el Typer app y comandos stub, y tests pytest que verifiquen `--help` y `--version`.

### 3. `cli/src/agents_cli/main.py`

```python
"""agent-run — operator CLI for the agents-orchestrator project."""
from __future__ import annotations

from importlib.metadata import PackageNotFoundError, version

import typer

app = typer.Typer(
    name="agent-run",
    help="Operator CLI for agents-orchestrator (V4).",
    no_args_is_help=True,
    add_completion=False,
)

policy_app = typer.Typer(help="Policy validation and ad-hoc checks.")
audit_app = typer.Typer(help="Inspect the local audit log.")

app.add_typer(policy_app, name="policy")
app.add_typer(audit_app, name="audit")


def _version() -> str:
    try:
        return version("agents-cli")
    except PackageNotFoundError:
        return "0.0.0+local"


def _version_callback(value: bool) -> None:
    if value:
        typer.echo(_version())
        raise typer.Exit()


@app.callback()
def _root(
    _v: bool = typer.Option(
        False, "--version", callback=_version_callback,
        is_eager=True, help="Show CLI version and exit."
    ),
) -> None:
    """Root callback (only used to wire --version)."""


@policy_app.command("validate")
def policy_validate() -> None:
    """Validate registries (stub; B/0/5 implements)."""
    typer.echo("policy validate: not implemented yet (B/0/5)")
    raise typer.Exit(code=2)


@policy_app.command("check")

if __name__ == "__main__":
```

### 5. Tests

`tests/cli/test_cli_scaffold.py`:

```python
from typer.testing import CliRunner

from agents_cli.main import app

runner = CliRunner()


def test_help_shows_subcommands():
    result = runner.invoke(app, ["--help"])
    assert result.exit_code == 0
    assert "policy" in result.stdout
    assert "audit" in result.stdout
    assert "approve" in result.stdout


def test_version_flag():
    result = runner.invoke(app, ["--version"])
    assert result.exit_code == 0
    assert result.stdout.strip()


def test_policy_validate_stub_returns_2():
    result = runner.invoke(app, ["policy", "validate"])
    assert result.exit_code == 2


def test_audit_show_stub_returns_2():
    result = runner.invoke(app, ["audit", "show"])
    assert result.exit_code == 2


def test_approve_stub_returns_2():
    result = runner.invoke(app, ["approve"])
    assert result.exit_code == 2
```
