## ¿Por que existe?

Exponer `shareArtifact` al LLM-orchestrator via MCP. El orchestrator llama `artifact.share` cuando quiere pasar un artefacto del coder al reviewer; el Gateway selecciona la version correcta (raw o sanitized) y devuelve `sharedArtifactId`.

## ¿Que hay que hacer?

Anadir tool `artifact.share` a `gateway/src/tools/artifact.js`. Schema Zod con `artifactId`, `requesterAgent`, `requesterRole`, `traceId`. Inyectar `registries`.

### 2. Tool

```javascript
import { shareArtifact } from "../services/artifact_share_service.js";

const ShareSchema = z.object({
  artifactId: z.string(),
  requesterAgent: z.string(),
  requesterRole: z.string(),
  traceId: z.string()
});

// inside buildArtifactTools({ registries }):
defineTool({
  name: "artifact.share",
  description: "Share an artifact with a target requester, applying policy and sanitization.",
  schema: ShareSchema,
  handler: async (a) => shareArtifact({ ...a, registries })
})
```
