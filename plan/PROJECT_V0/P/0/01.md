# P/0/1 - Codex real headless delegate

## Quick reference

| Campo | Valor |
|---|---|
| Stage | P - Codex adapter |
| Branch | `feature/P-0-1-codex-headless-delegate` |
| Depende de | P/0/0, K/0/3 |
| Esfuerzo | M (3-5h) |

## Por que existe?

P/0/0 deja Codex registrado pero dormido. Eso es correcto para el MVP original,
pero no permite usar Codex como agente codificador en la practica. Esta tarea
activa la primitiva minima util: `agent.delegate` headless real para Codex sobre
repos `unrestricted` o `internal`, manteniendo `restricted` denegado.

## Que hay que hacer?

Implementar `CodexAdapter.delegate` en modo real, configurable por
`AGENTS_CODEX_BIN`, con cwd allowlist, policy preflight, timeout, audit y tests
con binario fake. Codex sigue deshabilitado por defecto en el registry de
produccion.

## Plan de implementacion paso a paso

### 1. Branch

```bash
git checkout develop && git pull --ff-only || true
git checkout -b feature/P-0-1-codex-headless-delegate
```

### 2. Confirmar CLI local antes de hardcodear flags

No adivinar flags de Codex. La implementacion debe empezar documentando la
salida local relevante de:

```bash
codex --help
```

Si el binario no existe en la maquina del implementador, usar un binario fake
en tests y dejar `docs/adapters/codex.md` con la nota "real command pending
operator validation" hasta que el operador confirme la sintaxis.

### 3. Config

Anadir a `gateway/src/config.js`:

| Env var | Default | Descripcion |
|---|---|---|
| `AGENTS_CODEX_BIN` | `codex` | Binario Codex a invocar en modo real. |

Actualizar README y `client-config/README.md`.

### 4. Adapter

Actualizar `gateway/src/adapters/codex_adapter.js`:

- `checkEnabled()` sigue obligatorio.
- `delegate`:
  - policy preflight antes de proceso;
  - `assertSafeCwd`;
  - `SESSION_STARTED` y `SESSION_CLOSED`;
  - `spawnSync` o helper equivalente con timeout configurado;
  - salida `{ stdout, stderr, exitCode, dryRun: false }`;
  - errores auditados sin stack leak.
- `restricted` sigue denegado por policy/registry.

No implementar `spawn/ask/view/kill` aqui; eso queda para P/0/2.

### 5. Tests

Actualizar `tests/gateway/codex_adapter.test.js`:

- `disabled_codex_returns_clear_error`.
- `enabled_dry_run_delegate_works`.
- `enabled_real_delegate_uses_configured_fake_binary`.
- `real_delegate_rejects_cwd_outside_allowlist`.
- `codex_restricted_repo_denied_before_process`.

El test de real mode debe usar un script fake temporal como `AGENTS_CODEX_BIN`
para no depender del Codex real ni de red.

## Errores comunes

- Habilitar Codex por defecto en `policies/agent-capabilities.json`.
- Permitir Codex en `restricted`.
- Usar el binario real en tests de CI.
- Suponer flags no validados.

## Verificacion manual

```bash
npm --prefix gateway test -- ../tests/gateway/codex_adapter.test.js
```

Si el operador confirma Codex local:

```bash
AGENTS_DRY_RUN=0 AGENTS_CODEX_BIN=codex node --test tests/gateway/codex_adapter.test.js
```
