## ¿Por que existe?

V4 §17 reconoce que **artifact-mediated** cubre la mayor parte de la comunicacion entre hijos, pero existen casos `message-mediated` (preguntas cortas, replies) que no merecen un artifact. Sin un message store, la unica via es `agent.ask`, que requiere sesion supervised.

Este store es **MVP-light**: persistencia + scope por traceId + audit. Pub/sub real es V/0/1.

## ¿Que hay que hacer?

### 2. Repo

```javascript
import { getDb } from "../state.js";

export function createMessage(row) {
  getDb().prepare(`
    INSERT INTO messages(message_id, trace_id, from_id, to_id, body, created_at)
    VALUES (@messageId, @traceId, @fromId, @toId, @body, @createdAt)
  `).run(row);
  return row;
}

export function listMessagesByTrace(traceId) {
  return getDb().prepare("SELECT * FROM messages WHERE trace_id = ? ORDER BY created_at")
                .all(traceId);
}

export function getMessageScopedToTrace(messageId, traceId) {
  return getDb().prepare("SELECT * FROM messages WHERE message_id = ? AND trace_id = ?")
                .get(messageId, traceId) || null;
}
```
