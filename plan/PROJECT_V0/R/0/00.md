## ¿Por que existe?

`agent.spawn` devuelve `tmuxTarget` y `attachCommand`, pero el orchestrator-LLM puede haberlos perdido. Tener una tool dedicada `session.attach_info` permite recuperar el comando para anadirlo a una respuesta humano-facing ("ejecuta `tmux attach -t ag-...` para ver al hijo").

## ¿Que hay que hacer?

`gateway/src/tools/session.js` con `session.attach_info({ sessionId })` que consulta `session_repo` y retorna `{ tmuxTarget, attachCommand }`.

### 2. Tool

```javascript
import { defineTool, z } from "./tool_helpers.js";
import * as sess from "../core/repositories/session_repo.js";

export function buildSessionTools() {
  return [
    defineTool({
      name: "session.attach_info",
      description: "Return the tmux attach command for a supervised agent session.",
      schema: z.object({ sessionId: z.string() }),
      handler: async ({ sessionId }) => {
        const row = sess.getSession(sessionId);
        if (!row) return { error: "NOT_FOUND" };
        if (!row.tmux_target) return { error: "NOT_SUPERVISED" };
        return {
          sessionId,
          tmuxTarget: row.tmux_target,
          attachCommand: `tmux attach -t ${row.tmux_target}`
        };
      }
    })
  ];
}
```

Registrar en `tools/index.js`.
