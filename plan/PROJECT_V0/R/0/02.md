## ¿Por que existe?

Cuando el operador interviene a sabiendas en una sesion tmux (ej. corrige una shell que esta en bucle), queremos que pueda **registrar la intervencion** explicitamente. Esto complementa el detector best-effort de R/0/1.

## ¿Que hay que hacer?

Anadir tool `session.intervention_note({ sessionId, traceId, note, by })` que persiste un audit `HUMAN_TMUX_INTERVENTION_NOTE` con texto del operador.

## Plan paso a paso

### 1. Branch

```bash
git checkout develop && git pull --ff-only || true

```

### 2. Tool

```javascript
defineTool({
  name: "session.intervention_note",
  description: "Record a manual human intervention note tied to a session.",
  schema: z.object({
    sessionId: z.string(),
    traceId: z.string(),
    note: z.string().min(1),
    by: z.string().optional()
  }),
  handler: async ({ sessionId, traceId, note, by }) => {
    auditAppend({ type: "HUMAN_TMUX_INTERVENTION_NOTE",
                  sessionId, traceId, by: by || "operator",
                  note: note.slice(0, 4000) });
    return { ok: true };
  }
})
```

Registrar en `buildSessionTools()`.

### 3. Test

`tests/gateway/tool_session_intervention_note.test.js`:

- `records_note` returns `{ ok: true }`.
- `note_appears_in_audit` (query traceId, expect event with given note).
