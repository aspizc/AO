## ¿Por que existe?

Implementacion deterministica del sanitizer. Sin esto, las reglas son JSON inerte. La determinismo es critico: dos invocaciones con el mismo input deben producir output identico (caching, audit, tests reproducibles).

## ¿Que hay que hacer?

`gateway/src/core/sanitizer.js` con `sanitize(content, { kind, rules })`. Recorre reglas en orden y aplica reemplazos. Devuelve `{ sanitized, appliedRuleIds }`.

### 2. Implementacion

```javascript
import fs from "node:fs";
import path from "node:path";

let _rules = null;

export function configureSanitizer({ rulesPath }) {
  _rules = JSON.parse(fs.readFileSync(rulesPath, "utf-8")).rules;
}

export function sanitize(content, { kind }) {
  if (!_rules) throw new Error("sanitizer not configured");
  let out = String(content);
  const applied = [];
  for (const rule of _rules) {
    if (!rule.appliesTo.includes(kind)) continue;
    const re = new RegExp(rule.pattern, "g");
    if (re.test(out)) {
      out = out.replace(new RegExp(rule.pattern, "g"), rule.replacement);
      applied.push(rule.id);
    }
  }
  return { sanitized: out, appliedRuleIds: applied };
}
```

### 3. Test

`tests/gateway/sanitizer.test.js`:

```javascript
import { test } from "node:test";
import assert from "node:assert/strict";
import path from "node:path";
import { configureSanitizer, sanitize } from "../../gateway/src/core/sanitizer.js";

configureSanitizer({ rulesPath: path.resolve("policies/sanitization-rules.json") });

test("redacts_secret", () => {
  const { sanitized, appliedRuleIds } = sanitize(
    "api_key=sk-XXXXXXXXXXXXXXXXXXXX",
    { kind: "raw_code" }
  );
  assert.ok(sanitized.includes("REDACTED"));
  assert.ok(appliedRuleIds.includes("secret.token"));
});

test("redacts_absolute_path", () => {
  const { sanitized, appliedRuleIds } = sanitize(
    "/home/dev/project/private/key.pem",
    { kind: "raw_code" }
  );
  assert.ok(sanitized.startsWith("<HOME>/"));
  assert.ok(appliedRuleIds.includes("absolute.path"));
});

test("returns_applied_rules_deterministic", () => {
  const a = sanitize("uuid 123e4567-e89b-12d3-a456-426614174000", { kind: "raw_diff" });
  const b = sanitize("uuid 123e4567-e89b-12d3-a456-426614174000", { kind: "raw_diff" });
  assert.deepEqual(a, b);
});

test("non_applicable_kind_returns_unchanged", () => {
  const r = sanitize("api_key=sk-XXXXXXXXXXXXXXXXXXXX", { kind: "doc" });
  // 'doc' is not in appliesTo for any rule
  assert.equal(r.appliedRuleIds.length, 0);
});
```

## Errores comunes

- ❌ Aplicar reglas en orden no determinista (e.g. iterar sobre Map). Conserva orden del array JSON.
- ❌ Compilar regex una vez y mutar `lastIndex`. Crea un regex nuevo por iteracion o resetea.
- ❌ Hacer que `appliesTo` sea string en vez de array. Forzar array.

## Criterios de aceptacion

- [ ] Determinista (mismo input → mismo output).
- [ ] Reglas no aplicables devuelven content sin cambio.
- [ ] `appliedRuleIds` ordenadas por orden de regla.
