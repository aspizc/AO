### 2. `tests/cli/test_policy_validate_contract.py`

```python
from typer.testing import CliRunner
import shutil, pytest

from agents_cli.main import app

runner = CliRunner()


def test_valid_registries_exit_zero():
    if shutil.which("node") is None:
        pytest.skip()
    r = runner.invoke(app, ["policy", "validate"])
    assert r.exit_code == 0


def test_invalid_registries_exit_nonzero(tmp_path):
    if shutil.which("node") is None:
        pytest.skip()
    r = runner.invoke(app, ["policy", "validate", "--policies-dir", str(tmp_path)])
    assert r.exit_code != 0
```

### 3. Documentar en `docs/operator-cli-contract.md`

```markdown
# Operator CLI contract

These commands are part of the stable operator contract. Their exit
codes and required flags are not allowed to change without an ADR.

## `agent-run policy validate`

| Concern | Contract |
|---|---|
| Default policies dir | `<repo>/policies` (or `AGENTS_POLICIES_DIR`) |
| Exit 0 | All registries valid |
| Exit 1 | At least one registry invalid |
| Exit 2 | Environmental issue (node missing, validator missing) |
| Flags | `--policies-dir <path>`, `--json` |
| Output (human) | `OK ...` / `FAIL <code>: <msg>` |
| Output (json) | `{ "ok": bool, "code"?: str, "message"?: str, "counts"?: {...} }` |
```
