# W/0/0 - Codex real headless delegate (gpt-5 medium)

## Quick reference

| Campo | Valor |
|---|---|
| Stage | W - Codex real como coder |
| Branch | `feature/W-0-0-codex-headless-delegate` |
| Depende de | P/0/0 (codex dormido), V/0/1 (model plumbing) |
| Esfuerzo | M (3-5h) |
| Skills | adapters, child_process, policy |

## Por que existe?

P/0/0 dejo Codex registrado pero dormido; en modo real lanza
`ADAPTER_NOT_IMPLEMENTED`. El MVP2.0 necesita Codex como coder real. Esta tarea
implementa `CodexAdapter.delegate` headless real con `codex exec`, integrando la
seleccion de modelo/effort de Stage V y el sandbox `workspace-write`.

> Supera y reemplaza a la tarea historica P/0/1 anadiendo modelo y sandbox.

## Que hay que hacer?

Implementar `CodexAdapter.delegate` real: policy preflight, `assertSafeCwd`,
`codex exec -m <model> -c model_reasoning_effort="<effort>" -s workspace-write -C <cwd> <prompt>`,
timeout, audit de `SESSION_STARTED`/`SESSION_CLOSED`, errores sin stack leak.
`restricted` sigue denegado. Codex sigue `enabled: false` por defecto (se
habilita en W/0/2).

## Pre-requisitos

- V/0/1 mergeado: el service pasa `model`/`reasoningEffort` resueltos al adapter.
- `codex exec --help` validado (codex-cli 0.133.0). Si el binario no existe en la
  maquina del implementador, usar binario fake en tests y marcar el comando real
  como "pending operator validation" en `docs/adapters/codex.md`.

## Plan de implementacion paso a paso

### 1. Branch

```bash
git checkout develop && git pull --ff-only || true
git checkout -b feature/W-0-0-codex-headless-delegate
```

### 2. Config

Anadir a `gateway/src/config.js`:

| Env var | Default | Descripcion |
|---|---|---|
| `AGENTS_CODEX_BIN` | `codex` | Binario Codex en modo real. |
| `AGENTS_CODEX_SANDBOX` | `workspace-write` | Sandbox de `codex exec`. |

### 3. Adapter

En `gateway/src/adapters/codex_adapter.js`, `delegate`:

- `checkEnabled()` sigue obligatorio (Codex disabled por defecto).
- policy preflight con `action: "agent.delegate"` (incluye `model`/`reasoningEffort`).
- `assertSafeCwd(cwd, repoRoots)`.
- `SESSION_STARTED` -> spawn -> `SESSION_CLOSED`.
- Construir argv:
  ```js
  const args = ["exec",
    "-m", model,
    "-c", `model_reasoning_effort="${effort}"`,
    "-s", sandbox,
    "-C", safeCwd,
    prompt];
  ```
  con `model`/`effort` resueltos (default `gpt-5`/`medium` via registry) y
  `sandbox` = `AGENTS_CODEX_SANDBOX`.
- `spawnSync` con `timeout` configurado; salida `{ stdout, stderr, exitCode, dryRun:false, model, reasoningEffort }`.
- dry-run: salida simulada que incluye `model`, `effort`, `sandbox` y `cwd`.
- errores auditados sin stack leak (patron `auditAdapterError` ya existente).

No tocar `spawn/ask/view/kill` aqui (eso es W/0/1).

### 4. Tests

`tests/gateway/codex_adapter.test.js` (ampliar):

- `codex_restricted_repo_denied_before_process`.
- `disallowed_model_denied_before_process` (via V/0/0).

Binario fake temporal como `AGENTS_CODEX_BIN`; nunca el codex real en CI.
