## ¿Por que existe?

Cualquier cliente MCP (CLI generica, IDE, harness automatizado) tiene que poder conectar al Gateway. Este task entrega un **ejemplo neutro** + una checklist de smoke test que **no** menciona Cursor / Antigravity / ningun IDE concreto. Mantiene el principio "client-agnostic" del plan V4.

## ¿Que hay que hacer?

Crear `client-config/mcp.json.example` y `client-config/README.md`. Ambos genericos. Anadir test estructural.

### 2. `client-config/mcp.json.example`

```json
{
  "mcpServers": {
    "agents-gateway": {
      "transport": "stdio",
      "command": "node",
      "args": ["./gateway/src/mcp_server.js"],
      "env": {
        "AGENTS_WORKSPACE": "${PROJECT_ROOT}/workspace",
        "AGENTS_POLICIES_DIR": "${PROJECT_ROOT}/policies",
        "AGENTS_STATE_DB": "${PROJECT_ROOT}/workspace/state/state.db",
        "AGENTS_AUDIT_LOG": "${PROJECT_ROOT}/workspace/audit/events.jsonl",
        "AGENTS_TMUX_PREFIX": "ag-"
      }
    }
  }
}
```

> Nota: `${PROJECT_ROOT}` es un placeholder neutro. El cliente decidira como expandirlo.

### 3. `client-config/README.md`

```markdown
# Generic MCP client config

This directory contains a **client-agnostic** configuration example for
connecting any MCP-capable host (CLI tool, IDE, custom harness) to the
agents-gateway.

> Specific IDEs (Cursor, Antigravity, etc.) are **out of scope**. We do
> not maintain or test client-side configurations. Adapt the example
> below to your client's syntax.

## Files

- `mcp.json.example` — minimal MCP server entry, transport `stdio`,
  invoked via `node ./gateway/src/mcp_server.js`.

## Manual smoke checklist (host-agnostic)

1. From any directory, run:
   ```bash
   node ./gateway/src/mcp_server.js < /dev/null
   ```
   The process must start, log to stderr (`gateway connected`), and exit
   when stdin closes. **stdout must remain empty**.

2. Connect any MCP client and call `tools/list`. The response must
   include the tool `policy.check`.

3. Call `policy.check` with:
   ```json
   { "agent": "claude-code", "role": "orchestrator", "action": "policy.check" }
   ```
   The response must contain `"decision": "allow"`.

4. Inspect `workspace/audit/events.jsonl`. There must be a
   `POLICY_DECIDED` event for the previous call.

If your specific MCP host requires a different config format
(`mcp_servers.json`, `claude.json`, IDE-specific entries, etc.), adapt
the example, but keep the server name `agents-gateway` and the
environment variables.
```

### 4. Test estructural

`tests/structure/test_client_config.py`:

```python
import json
from pathlib import Path

CFG = Path(__file__).resolve().parents[2] / "client-config" / "mcp.json.example"
README = Path(__file__).resolve().parents[2] / "client-config" / "README.md"


def test_generic_mcp_example_exists():
    assert CFG.is_file()
    assert README.is_file()


def test_generic_mcp_example_is_valid_json():
    json.loads(CFG.read_text(encoding="utf-8"))


def test_generic_mcp_example_points_to_gateway():
    data = json.loads(CFG.read_text(encoding="utf-8"))
    server = data["mcpServers"]["agents-gateway"]
    assert "gateway/src/mcp_server.js" in " ".join(server["args"])


def test_generic_mcp_example_uses_stdio_transport():
    data = json.loads(CFG.read_text(encoding="utf-8"))
    assert data["mcpServers"]["agents-gateway"]["transport"] == "stdio"


def test_generic_mcp_example_has_no_ide_specific_keys():
    text = CFG.read_text(encoding="utf-8")
    for forbidden in ("cursor", "Cursor", "antigravity", "Antigravity",
                       ".mdc", ".cursor"):
        assert forbidden not in text, f"forbidden keyword found: {forbidden}"


def test_readme_marks_specific_ides_out_of_scope():
    text = README.read_text(encoding="utf-8")
    assert "out of scope" in text.lower()
```
