## ¿Por que existe?

El operador necesita responder approvals **desde terminal**, sin abrir IDE alguno. Esto cierra el loop async-first: `request` queda pending → operador ve audit/poll → ejecuta `agent-run approve <id> --decision granted`.

Cliente IDE-specific (Cursor/Antigravity) explicitamente fuera de scope.

## ¿Que hay que hacer?

Reemplazar el stub `approve` (de A/0/3) con una invocacion real al servicio Node via subprocess. Flags: `--decision granted|denied`, `--note`.

### 2. Helper Node

`gateway/scripts/approval-respond.mjs`:

```javascript
#!/usr/bin/env node
import { configureAudit } from "../src/core/audit.js";
import { initState } from "../src/core/state.js";
import { loadConfig } from "../src/config.js";
import { respond } from "../src/services/approval_service.js";

const args = process.argv.slice(2);
const get = (f) => { const i = args.indexOf(f); return i >= 0 ? args[i+1] : null; };

const config = loadConfig();
initState({ stateDb: config.stateDb });
configureAudit({ auditLog: config.auditLog });

const r = respond({
  approvalId: get("--approval-id"),
  decision:   get("--decision"),
  decidedBy:  get("--decided-by") || "operator",
  note:       get("--note") || ""
});
process.stdout.write(JSON.stringify(r));
```

### 3. CLI

```python
@app.command("approve")
def approve(
    approval_id: str = typer.Argument(...),
    decision: str = typer.Option(..., "--decision", "-d", help="granted|denied"),
    note: str = typer.Option("", "--note"),
    output_json: bool = typer.Option(False, "--json"),
) -> None:
    if shutil.which("node") is None:
        typer.echo("error: node not on PATH", err=True); raise typer.Exit(2)
    if decision not in ("granted","denied"):
        typer.echo("error: --decision must be granted|denied", err=True); raise typer.Exit(2)
    script = REPO_ROOT / "gateway" / "scripts" / "approval-respond.mjs"
    cmd = ["node", str(script),
           "--approval-id", approval_id,
           "--decision", decision,
           "--note", note]
    proc = subprocess.run(cmd, capture_output=True, text=True, check=False)
    data = json.loads(proc.stdout or "{}")
    if output_json:
        typer.echo(json.dumps(data))
    else:
        if "error" in data:
            typer.echo(f"error: {data['error']}", err=True); raise typer.Exit(1)
        typer.echo(f"{approval_id}: {data.get('status', 'unknown')}")
```
