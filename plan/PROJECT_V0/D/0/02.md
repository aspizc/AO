# D/0/2 — Runtime path configuration

## Quick reference

| Campo | Valor |
|---|---|
| Stage | D — Audit Log y Runtime Config |
| Branch | `feature/D-0-2-runtime-path-config` |
| Depende de | A/0/2, D/0/0 |
| Esfuerzo | S (1h) |

## ¿Por que esta tarea existe?

Hasta ahora `config.js` (A/0/2) tenia stubs. Ahora que hay audit y vendra DB, necesitamos paths runtime resueltos contra `AGENTS_WORKSPACE` y defaults locales al repo. Esto cierra el principio "el Gateway no escribe fuera del workspace por defecto".

## ¿Que hay que hacer?

Reforzar `gateway/src/config.js` para que: (1) acepte env absolutas, (2) resuelva relativas bajo `AGENTS_WORKSPACE`, (3) caiga en `<repo>/workspace/...` si nada esta seteado, (4) documente env vars en README.

```javascript
return {

```

### 3. Test

`tests/gateway/config_paths.test.js`:

```javascript
import { test } from "node:test";
import assert from "node:assert/strict";
import path from "node:path";
import { loadConfig } from "../../gateway/src/config.js";

test("relative_paths_resolve_under_workspace", () => {
  const c = loadConfig({
    AGENTS_WORKSPACE: "/tmp/aw",
    AGENTS_AUDIT_LOG: "audit/x.jsonl"
  });
  assert.equal(c.auditLog, "/tmp/aw/audit/x.jsonl");
});

test("absolute_paths_are_preserved", () => {
  const c = loadConfig({ AGENTS_AUDIT_LOG: "/var/log/y.jsonl" });
  assert.equal(c.auditLog, "/var/log/y.jsonl");
});

test("workspace_defaults_are_local", () => {
  const c = loadConfig({});
  assert.ok(c.workspace.endsWith("/workspace"));
  assert.ok(c.auditLog.includes("/workspace/audit/"));
});

test("approval_max_wait_ms_default_60s", () => {
  const c = loadConfig({});
  assert.equal(c.approvalMaxWaitMs, 60_000);
});

test("dry_run_flag", () => {
  assert.equal(loadConfig({ AGENTS_DRY_RUN: "1" }).dryRun, true);
  assert.equal(loadConfig({}).dryRun, false);
});
```

### 4. Documentar env vars

Anadir al README seccion "Environment variables":

```markdown
## Environment variables

| Var | Default | Description |
|---|---|---|
| `AGENTS_WORKSPACE` | `<repo>/workspace` | Root for artifacts, audit, state. |
| `AGENTS_POLICIES_DIR` | `<repo>/policies` | Registries dir. |
| `AGENTS_STATE_DB` | `<workspace>/state/state.db` | SQLite path. |
| `AGENTS_AUDIT_LOG` | `<workspace>/audit/events.jsonl` | Audit JSONL. |
| `AGENTS_ARTIFACT_STORE` | `<workspace>/artifacts` | Artifact store root. |
| `AGENTS_TMUX_PREFIX` | `ag-` | tmux session prefix. |
| `AGENTS_REPO_ROOTS` | (empty) | Colon-separated list of cwd allowlist. |
| `AGENTS_APPROVAL_MAX_WAIT_MS` | `60000` | Server-side cap on `approval.wait`. |
| `AGENTS_DRY_RUN` | `0` | If `1`, adapters do not spawn real subprocesses. |
```
