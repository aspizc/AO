## ¿Por que existe?

Sin policy, `artifact.get` es un agujero: cualquiera puede pedir cualquier artifactId. Aqui anclamos:

- `requesterAgent` y `requesterRole` son obligatorios.
- Se evalua policy con artifact metadata (`kind`, `classification`).
- Audit `POLICY_DECIDED` por cada call.
- Antes de M, el deny es **deny**. M/0/2 anadira el sanitized fallback.

## ¿Que hay que hacer?

Refactor el handler de `artifact.get` para llamar `evaluate(...)` con el contexto correcto. Si decision != allow, devolver `{ error: "POLICY_DENIED", decision }`.

```javascript
import { evaluate } from "../core/policy_engine.js";

// inside artifact.get handler:
async ({ artifactId, requesterAgent, requesterRole }) => {
  const row = store.get({ artifactId });
  if (!row) return { error: "NOT_FOUND" };
  const decision = evaluate({
    agent: requesterAgent || "unknown",
    role: requesterRole || "unknown",
    action: "artifact.get",
    artifactKind: row.kind,
    artifactClassification: row.classification
  }, registries);
  auditAppend({ type: "POLICY_DECIDED", traceId: row.trace_id,
    context: { action: "artifact.get", artifactKind: row.kind, classification: row.classification },
    decision: decision.decision, ruleId: decision.ruleId });
  if (decision.decision !== "allow") {
    return { error: "POLICY_DENIED", decision };
  }
  return { ...row, content: row.content.toString("utf-8") };
}
```

> Inyeccion: `buildArtifactTools({ registries })` ahora recibe registries.
