## ¿Por que existe?

`approval.wait` corto no cubre approvals de horas. Temporal debe esperar una signal sin bloquear procesos ni perder estado.

## ¿Que hay que hacer?

El nodo de approval envia `approval.request` via Gateway y espera `workflow.wait_for_signal("approval_response", timeout=86400)`.

## Plan de implementacion

1. Crear activity para `approval.request`.
2. Implementar signal `approval_response`.
3. Integrar timeout configurable con default 24h.
4. Conectar respuesta humana al workflow sin auto-resolver `NEVER_AUTO`.
5. Tests para aprobado, rechazado y timeout.

## Verificacion: Gateway contract inmutable

La aprobacion se solicita via Gateway. Temporal solo espera la respuesta durable.
