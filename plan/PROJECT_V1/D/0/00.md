## ¿Por que existe?

Antes de convertir grafos en workflows durables hace falta un worker Temporal importable, testeable y configurado sin tocar el Gateway.

## ¿Que hay que hacer?

Crear scaffold de worker en `orchestrator-langgraph` con configuracion de conexion, task queue y test de import.

## Plan de implementacion

1. Anadir dependencias Temporal Python al paquete.
2. Crear modulo de worker y entrypoint.
3. Configurar `TEMPORAL_ADDRESS` y task queue por env.
4. Asegurar logs JSON a stderr.
5. Test estructural de import y configuracion default.

## Verificacion: Gateway contract inmutable

El worker todavia no ejecuta tools; no toca MCP ni Gateway.
