## ¿Por que existe?

V1 no debe cerrarse solo porque las piezas existen. Hace falta un gate explicito que verifique criterios de salida, invariantes y decisiones arquitectonicas.

## ¿Que hay que hacer?

Crear checklist de Gate V1 y ADR-V1-06 para formalizar observabilidad, empaquetado y criterios de cierre. Verificar que ADR-V1-01 a ADR-V1-06 quedan presentes y alineados.

## Plan de implementacion

1. Crear checklist V1 con criterios tecnicos, operativos y de seguridad.
2. Incluir comprobaciones de Gateway contract, approvals, Temporal, Postgres, Redis y OTel.
3. Verificar que ADR-V1-01 a ADR-V1-05 existen y referencian decisiones vigentes.
4. Crear `docs/adr/ADR-V1-06-observability-and-packaging.md`.
5. Ejecutar pruebas y smoke checks requeridos por el gate.
6. Registrar resultado del gate y cualquier excepcion aprobada.

## Verificacion: Gateway contract inmutable

El gate debe fallar si hay cambios incompatibles en tools MCP, si el orchestrator accede a APIs internas del Gateway o si la observabilidad altera semantica de requests/responses.

## Tests requeridos

- Suite relevante de Gateway.
- Suite relevante de orchestrator-langgraph.
- Smoke `docker compose` completo.
- Smoke de workflow durable con Postgres, Redis y trazas OTel visibles.
- Validacion documental de ADR-V1-01 a ADR-V1-06.

## Errores comunes

- Convertir el checklist en una lista informativa sin comandos verificables.
- Aprobar V1 con trazas parciales o sin correlacion de `trace_id`.
- Olvidar validar `NEVER_AUTO` en el gate final.
- Crear ADR-V1-06 sin relacionarlo con los criterios de salida.

## Criterios de aceptacion

- [ ] Checklist Gate V1 completo y verificable.
- [ ] ADR-V1-06 presente y formaliza observabilidad/empaquetado.
- [ ] ADR-V1-01 a ADR-V1-06 quedan formalizados.
- [ ] Todos los criterios de salida de Stage E quedan marcados o bloqueados explicitamente.

## Definition of Done

- [ ] Gate V1 ejecutado con resultado documentado.
- [ ] Evidencia de tests y smoke checks anexada o referenciada.
- [ ] Sin cambios incompatibles en Gateway contract.
- [ ] Stage E queda listo para cierre de PROJECT_V1.
