## ¿Por que existe?

V1 garantiza que artefactos, approvals y audit son indistinguibles aguas abajo si el caller es LLM o LangGraph. Esta tarea convierte esa garantia en un test automatizado.

## ¿Que hay que hacer?

Crear un test comparativo que corre el flujo `delegate->review` por el path LLM con fixtures/mock y por el grafo LangGraph en dry-run. Compara eventos de audit normalizados campo a campo.

## Plan de implementacion paso a paso

1. Extraer fixtures de audit del LLM-path de V0 o crear fixture equivalente documentado.
2. Crear `orchestrator-langgraph/tests/test_audit_parity.py`.
3. Implementar `normalize_audit_event(event)` eliminando timestamps, IDs aleatorios, `session_id` y `task_id`.
4. Correr grafo dry-run y capturar eventos generados por el `GatewayClient` mockeado.
5. Comparar `event_type`, `tool_name`, `actor_role` y presencia de `trace_id`.
6. Documentar en comentario los campos no comparables.

## Errores comunes

- Comparar timestamps.
- No normalizar `session_id` y `task_id`.
- Anadir campos nuevos al audit event desde el cliente LangGraph. Solo el Gateway escribe audit.

## Verificacion: Gateway contract inmutable

El test demuestra paridad sin adaptar tools ni audit writer para LangGraph.
