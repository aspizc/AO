## ¿Por que existe?

Antes de escribir un nodo LangGraph hay que fijar el contrato fisico del nuevo componente: directorio, nombre del paquete Python y layout de carpetas. Las tareas posteriores no deben inventar paths ni mezclar codigo de negocio en el scaffold.

## ¿Que hay que hacer?

Crear `orchestrator-langgraph/` con `pyproject.toml`, estructura de paquete `orchestrator_langgraph/`, carpetas para `graphs/`, `nodes/`, `client/` y `tests/`, y un test estructural que ancle el layout.

## Plan de implementacion paso a paso

1. Branch desde `develop` o desde `main` si `develop` no existe.
2. Crear `orchestrator-langgraph/src/orchestrator_langgraph/{graphs,nodes,client}/`.
3. Crear `orchestrator-langgraph/tests/`.
4. Crear `pyproject.toml` minimo: nombre `orchestrator-langgraph`, Python `>=3.11`, deps `langgraph` y `mcp`.
5. Crear `__init__.py` en el paquete y subpaquetes.
6. Crear `orchestrator-langgraph/tests/structure/test_langgraph_layout.py`.
7. Verificar con `python -c "import orchestrator_langgraph"` desde un entorno que incluya `src/`.
