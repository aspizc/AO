## Problem

Artifact bytes and database metadata cannot share a native transaction; crashes
can leave a visible row without committed content or orphan content without
lineage.

## Scope

- Stage content privately, verify size/digest/classification, and atomically
  publish metadata/reference through a recoverable state machine.
- Use durable operation/outbox identity for finalize/cleanup.
- Reconcile staged, committed, missing, corrupt, and orphaned objects without
  exposing partial content.

## Non-scope

- No destructive orphan purge without retention evidence, public staging path,
  mutable committed artifact, or remote object-store migration requirement.

## TDD RED

Crash at write/fsync/rename/metadata/outbox boundaries; inject digest mismatch,
partial file, duplicate finalize, missing committed content, orphan age race,
and cross-operation staging access.

## TDD GREEN

Implement private staging, atomic local publish primitive, artifact state
transitions, reconciliation, and bounded cleanup.

## Acceptance criteria

- [ ] Readers see either a complete verified artifact or no artifact.
- [ ] Exact finalize retry is idempotent; changed digest fails closed.
- [ ] Restart reconciles every partial state deterministically.
- [ ] Staging and orphan cleanup respect isolation/retention.

## Verification

Run artifact crash-matrix/reconciliation/integrity/permission tests and storage
migration recovery; then `bash scripts/ci.sh` and `git diff --check`.
