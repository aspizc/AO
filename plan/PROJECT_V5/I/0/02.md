## Problem

Long-running approval/review/recovery flows need durable replay, but workflow
history must not contain raw restricted data or create a second Gateway writer.

## Scope

- Define a versioned Temporal workflow using opaque IDs/digests/status only and
  one authenticated internal Gateway activity channel.
- Validate actual Gateway activity envelopes with integer `exitCode`; only
  `exitCode == 0` plus the expected structured implement/test/review result may
  advance, and invented `passed`/`status` fields carry no authority.
- Stop before approval or push intent on reviewer KO, nonzero exit, missing or
  ambiguous fields, or parse failure.
- Reuse canonical lifecycle, durable operations, signed approval, review gate,
  and completion blockers rather than copying rules into workflow code.
- Prove deterministic replay, worker upgrade/drain, reset/new run, signal hints,
  and crash recovery.

## Non-scope

- No workflow-side DB/audit/artifact access, second Gateway, raw prompt/diff/
  output in history, signal as approval authority, or silent fallback.

## Acceptance criteria

- [ ] Replay/restart yields one effective operation per logical step.
- [ ] Real integer `exitCode` and structured results are the only success oracle.
- [ ] KO/nonzero/missing/parse failure never reaches approval or push intent.
- [ ] Approval/review/completion are resolved authoritatively by Gateway.
- [ ] History contains only allowlisted opaque values.
- [ ] Upgrades drain old histories without nondeterministic replay.

## Verification

Run real-envelope/KO, unit/replay/fault/history-leak tests plus the required
ephemeral Temporal/Gateway lane; then `bash scripts/ci.sh` and
`git diff --check`.
