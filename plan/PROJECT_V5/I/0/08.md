| Field | Value |
|---|---|
| Status | `planned` |

| Depends on | `C/0/02`, `F/0/04`, `I/0/02`, `I/0/06`, `I/0/07` |

## Problem

LangGraph and Temporal expose duplicate implement-test-review-push paths, the
selector can preserve silent fallback, and accepted ADRs do not identify one
candidate-tested production architecture.

## Scope

- Select the I/0/02 Temporal workflow and I/0/06 worker as the only production
  ITRP after their candidate passes I/0/07 and the independent review gate.
- Add explicit opt-in, migration, drain, rollback, and no-fallback semantics;
  existing histories finish on their compatible worker build.
- Remove production imports/entry points/tests/docs for the duplicate LangGraph
  ITRP while preserving its independent plan-refine capability.
- Reconcile ADR-001/002 and V1 ADRs with the as-built selector, workflow,
  Gateway ownership, stores, worker packaging, and retirement decision.

## Non-scope

- No change to I/0/02 envelope/KO/replay semantics, rewrite of existing Temporal
  histories, removal of LangGraph plan-refine, real remote push, or release/tag
  publication.

## TDD RED

Detect both production ITRP imports/entry points, silent fallback, a new run on
the legacy path, incompatible history drain, rollback without version routing,
an unreviewed/untested selector target, and ADR/runtime/packaging contradictions.

## TDD GREEN

Add the explicit selector/cutover manifest, history-drain and rollback guards,
legacy-import absence tests, plan-refine preservation test, and reconciled
accepted/superseded ADR set.

## Acceptance criteria

- [ ] Exactly one production ITRP entry point and selector target remains.
- [ ] Cutover requires the reviewed candidate and full-stack evidence.
- [ ] Existing histories drain; new runs cannot enter the retired path.
- [ ] Rollback is explicit, version-compatible, and never a silent fallback.
- [ ] Accepted ADRs and shipped docs describe the same runtime topology.

## Verification

Run selector/import uniqueness, history drain/version routing, rollback, full
I/0/07 stack, plan-refine preservation, and ADR consistency tests; then
`bash scripts/ci.sh` and `git diff --check`.
