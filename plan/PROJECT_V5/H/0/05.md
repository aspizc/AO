## Problem

Owner-local credentials, paths, caches, and mocks can make the hero flow appear
ready without proving that real agents work portably through the protected
policy, review, approval, and audit boundaries.

## Scope

- Add an explicit protected/manual lane that bootstraps a clean disposable
  checkout under a non-owner home/UID/path using only declared locks and
  configuration.
- Run real supported coder and independent reviewer CLIs on a synthetic
  repository through the actual Gateway, sandbox, policy, artifact,
  sanitization, signed approval, review, and audit surfaces.
- Exercise `E/0/05` session-grant, one-shot-grant, and no-grant pending paths
  without reimplementing their authority or consent assertions.
- Enforce scoped credentials, global provider/resource budgets, no inherited
  control plane, candidate-bound evidence, deterministic cleanup, and failure
  rather than skip when the protected lane is selected.
- Remove push credentials and verify no remote ref, merge, tag, or publication
  is attempted or changed; the run ends with an inspectable no-push outcome.

## Non-scope

- No personal/restricted production repository, unattended credential
  enrollment, automatic rerun/spend, shared-service mutation, or real push.

## TDD RED

Inject owner-local paths/caches, missing lock/bootstrap step, mock/dry-run
adapter, absent provider, inherited control credentials, skipped policy/review/
approval/audit evidence, budget excess, secret canaries, and a push attempt.

## TDD GREEN

Build the protected non-owner harness, scoped provider adapters and test signer,
portable bootstrap, no-push remote guard, evidence manifest, and cleanup
attestation.

## Acceptance criteria

- [ ] A clean non-owner environment completes the selected real-agent flow.
- [ ] Real provider processes cross the same policy/sandbox/review gates as users.
- [ ] Sanitization, approval consumption, and audit evidence are visibly proven.
- [ ] No owner-local path, credential, raw restricted byte, or control handle leaks.
- [ ] The remote repository is byte/ref-identical and no push credential exists.

## Verification

Run the protected lane on a disposable non-owner runner in both reviewer
orders, assert candidate/evidence and no-push guards, scan canaries, and run
cleanup twice; then `bash scripts/ci.sh` and `git diff --check`.
