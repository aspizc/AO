## Problem

Users cannot tell whether dependencies, agent login, config, repository,
policy, runtime isolation, and Redis coordination are ready before starting a
workflow.

## Scope

- Ship a minimal synthetic sample repository/plan/profile with no personal data.
- Provide one documented, script-disabled lock-graph materialization from a
  clean candidate archive with no existing `node_modules`, virtualenv,
  generated files, owner-local paths, or undeclared tools. It must not
  represent an unbuilt native add-on as a runnable Gateway install.
- Add `doctor` checks for supported runtime/dependencies, model CLI/login,
  config paths, canonical repository binding, policy/profile, isolation, state
  ownership, Redis status/scope, and required ports/services.
- Produce safe human and JSON diagnostics with remediation links.

## Characterized product contract

`doctor` is a read-only preflight, not a second control plane. Its stable JSON
projection is versioned and contains only:

```text
schemaVersion, profileId, status(pass|warn|fail),
checks[{id, status, code, summary, remediation{doc, anchor}}]
```

Checks are deterministically ordered. Renderers never receive raw command
output, exception causes/stacks, configuration values, credentials, argv, or
personal paths. Exit `0` means no failed required check, exit `1` means at
least one required check failed, and exit `2` is reserved for invalid
invocation or an internal contract violation.

### DOCTOR DTO admission boundary

Trials 1–6 proved that portable Python cannot make these DTO classes
un-subclassable in the presence of arbitrary, non-cooperative metaclasses and
multiple inheritance. Trial 7 therefore removes runtime finality from the
security claim. Class-hook immutability remains defense in depth only. The
security boundary is exact-type admission plus deep identity/provenance
validation before any attacker-controlled `getattr`, iteration, callable,
equality, hash, `repr`, `str`, `bool`, or call:

- Deep identity is not exact type plus value equality. Every accepted DTO is
  module-issued and recorded in a private provenance ledger keyed by `id`;
  the retained object reference is compared only with `is`, never DTO
  equality/hash. Its complete scalar/graph snapshot is registered only after
  validation finishes. An exact but unissued `object.__new__` forgery, missing
  slot, post-issuance drift, cycle, or container subclass is rejected.
- The public canonical registry and every private canonical definition/outcome
  map must be the exact issued objects and remain identity-consistent before
  use. No public copy can substitute for or silently rebind private authority.
- `run_doctor` accepts only an exact `tuple` containing all six issued, exact
  `ProbeBinding` objects and their exact `CheckId` values. It validates the
  whole tuple, then captures a safe `(check_id, probe)` snapshot before the
  first intentional probe call. A callable is a trusted capability, not data:
  it is invoked exactly once only after the whole snapshot passes, and no
  callable-identity claim is made.
- Probe output is admitted only when it is an issued exact
  `ProbeObservation` and all exact fields match its provenance snapshot before
  any lookup or hash.
- Every constructor plus `DoctorRun`, `validate_result`, `project_result`,
  `render_json`, and `render_human` is a public boundary. Exact type alone is
  insufficient, so each boundary revalidates the root and complete nested
  scalar/object graph. A validator returns the complete safe projection or
  immutable snapshot its consumer uses; renderers never validate and then
  reread the caller-owned DTO.
- The RED/GREEN matrix covers all eight DTOs (`Remediation`,
  `OutcomeDefinition`, `CheckDefinition`, `ProbeObservation`, `ProbeBinding`,
  `DoctorCheck`, `DoctorResult`, and `DoctorRun`) at every applicable boundary
  with a hostile subclass; unissued exact forgery; missing slots;
  post-issuance same-value, different-value, and hostile mutation; cycles; and
  container subclasses. Rejection causes zero DOCTOR-triggered observable
  callbacks and raises the exact static `DoctorContractError` via
  `raise ... from None`, with both `__cause__` and `__context__` equal to
  `None`. Ordinary probe failures keep their allowlisted static outcome, while
  `BaseException` propagates unchanged.

This boundary does not claim to prevent arbitrary code in an attacker-defined
metaclass body before the object is presented to DOCTOR. It also excludes an
attacker already able to mutate this module's globals, DTO classes, private
ledger/maps, or Python builtins.

#### Trial 8 descriptor and issuance-lifecycle binding

Trial 7 received independent KO at `822ca1c`: every class-observable
`_TrackedSlot` returned its original writable `member_descriptor`, so a caller
could write and restore a field without advancing permanent mutation state.
Its process-global ledger also strongly retained every issued root, nested
snapshot, and probe callable indefinitely.

Trial 8 keeps exact-type/private-issuance admission but replaces those two
mechanisms:

- an installed tracked descriptor has no method, property, slot, `__dict__`,
  closure, or other class-observable value that returns the raw writable slot;
  the raw slot is reachable only through a module-private authority map, which
  is already outside the stated attacker boundary;
- every supported set or delete path still advances irreversible taint before
  storage is touched, including same-value and different-then-restored writes;
- an issuance record retains only a weak reference to its exact root plus
  irreversible mutation state. It does not retain the root, a nested DTO,
  snapshot, container, probe callable, or callable closure;
- weak-reference retirement removes a record only when both its integer key
  and exact weak-reference object still match. A delayed callback cannot
  remove a replacement record, and lookup never invokes DTO equality, hashing,
  formatting, or caller callbacks;
- exact type, live weak-reference identity, and untainted state are checked
  before known slots are read once into a local immutable safe snapshot.
  Nested issued DTOs repeat the same admission. Consumers use that snapshot
  and never reread caller-owned fields; and
- failed constructors create no record. Discarded bindings and completed
  result graphs return the ledger to its live baseline after collection,
  while the canonical registry remains live only because its public/private
  roots remain live.

The Trial 8 RED matrix reproduces the Trial 7 raw-descriptor route across all
eight DTOs, proves that no raw writable slot remains reachable from public
class/descriptor observables, and repeats same-value plus
different-then-restored mutations at observation, binding, registry, run,
validation, projection, and renderer boundaries. A lifecycle matrix performs
repeated discarded runs and discarded weak-referenceable probe capabilities,
then proves that ledger size and referent liveness return to the canonical
baseline after collection. It also exercises a delayed stale retirement
callback against a replacement record. All rejection paths retain the
zero-callback/static-error contract.

#### Trial 8 KO and Trial 9 correction gate

Trial 8 preserves its request and independent KO result at `6a56e6d` and
`530eec7`; its code is not integrated. It correctly closes the raw-descriptor
and ordinary strong-retention defects, but Trial 9 must make the remaining
protocol consistent:

- issuance identity/taint validation and complete recursive snapshot capture
  are one atomic admission operation with respect to every supported
  descriptor write/delete and weak retirement. A mutation cannot land after
  the untainted check and before a field/capability read; `run_doctor` never
  invokes a post-taint binding;
- the consistency mechanism is reentrant for nested issued DTOs, is released
  before intentional probe execution, and consumers still use only their
  immutable local snapshot;
- retirement identity does not live in externally writable state on the
  weak-reference object returned by `weakref.getweakrefs()`. The callback may
  close over a scalar key, retains no root/graph/capability, and still deletes
  only an exact key-plus-reference match; and
- normal collection, externally observed weak references, attempted weakref
  mutation/deletion, delayed stale callbacks, failed construction, and
  integer-key replacement all return the ledger to its canonical live
  baseline without deleting a replacement.

Trial 9 REDs deterministically schedule a valid different-value result
mutation and a binding-capability replacement between admission phases for
every public result boundary. They also inventory public weak references for
all eight DTOs and prove that no supported operation can disable retirement.
Thread-stress evidence supplements but never replaces deterministic barriers.

The Trial 9 review also adjudicates the remaining Python-introspection caveat:
`_TrackedSlot.__set__.__func__.__globals__` exposes the module namespace, from
which the current private storage map can be read and its raw
`member_descriptor` selected. Reading the map and then writing through that
descriptor does not itself mutate the map, so the Trial 8 wording is
internally inconsistent.

The binding disposition is explicit: DOCTOR is a closed-value admission
boundary for callers that use its supported public module/DTO API; it is not
an isolation boundary against arbitrary code already executing in the same
Python process and traversing function `__globals__` into underscore-prefixed
module state. Pure Python functions cannot make their globals namespace
opaque. Turning that same-process reflection into a security boundary would
require a native or process-isolated component, which contradicts this
stdlib-only preflight and belongs to `D/0/02`, not another DTO trick.

Trial 9 therefore updates task/product documentation and tests to exclude both
read and mutation access to the private ledger/storage/authority maps. It
removes the absolute “no class-observable route” claim and replaces it with
the exact supported-surface claim: no raw slot is returned by DTO/class/
descriptor attributes, defaults, keyword defaults, closures, or other public
values without crossing into the private module namespace. This is a
documented in-process trust boundary, never runtime finality. Standard
`weakref.getweakrefs(dto)` remains in scope because it operates directly on a
public DTO without traversing private module state; its writable retirement
authority must still be removed.

### Pure-Python reflection boundary

The DOCTOR retirement criterion is intentionally narrower than hostile
same-process isolation. Retirement/lifecycle-specific writable authority must
expose no ordinary Python function state: issued DTOs have no `__del__`
retirement hook, and the callback on the publicly discoverable issuance weak
reference is slots-only with a built-in call surface. Exact record, reference,
callback, cleanup, taint, and admission guards remain required.

A normal pure-Python class cannot expose zero ordinary function dictionaries.
Every instance necessarily reaches ordinary inherited, generated, or
class-defined dunder methods such as `__repr__`, `__eq__`, `__init__`,
`__setattr__`, and `__delattr__`; their bound `__func__.__dict__` remains
writable. The Trial 12 independent review proved this on Python 3.11 and 3.13.
Using that residual requires same-process Python execution, a live issued DTO
or the live referent returned by its issuance weak reference, and the loaded
Doctor module. It is therefore `V5-H-0-01-D01` in the Project V5
[deferred register](../../DEFERRED.md), owned by `D/0/02`, rather than a
DOCTOR failure under the operator-ratified narrowed criterion. This boundary
does not permit reintroducing a Python `__del__` finalizer or Python-function
state on the discovered callback.
