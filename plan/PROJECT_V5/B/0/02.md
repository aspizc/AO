## Problem

Raw tools leave every orchestrator to schedule heartbeats, interpret lease
loss, and safely create a replacement identity; missed turns silently remove a
participant.

## Scope

- Ship a reusable factory for single-use client/profile instances that manage
  register, jittered heartbeat, lease-loss detection, and bounded
  re-registration.
- Keep lease tokens private and never persist them in prompts, artifacts, audit,
  review files, or command output.
- Surface explicit states (`starting`, `ready`, `degraded`, `rejoining`,
  `stopped`) and safe recovery guidance.

## Non-scope

- No autonomous task execution, authority transfer, infinite retry, or hidden
  fallback to a different scope.

## TDD GREEN

Implement one locally abortable, epoch-fenced client loop over the public
direct contract with single-flight register/heartbeat and bounded exponential
backoff. The factory can create any number of clients, but each returned client
is deliberately single-use: terminal `stop()` resolves without waiting for an
unbounded dependency call, fences every late completion, and performs detached
best-effort cleanup where credentials become available.

Delivered:

- `gateway/src/coordination_client.js` exports the four-method managed profile;
- `gateway/src/coordination.js` re-exports the factory beside the direct
  service;
- fake clock/scheduler tests cover the normal cadence, jitter bounds,
  no-action-retry credential injection, concurrent lease loss, retry
  exhaustion, canonical protocol/scope/identity validation, pending
  status/register/heartbeat/unregister calls, late cleanup, idempotent bounded
  stop, date overflow, and status leakage; and
- the Gateway README, architecture, coordination runbook, and accepted V5 ADR
  describe the implemented state machine and recovery contract.

## Acceptance criteria

- [x] Presence survives normal reasoning turns without caller-managed timers.
- [x] Lease loss creates at most one replacement participant.
- [x] Stop is idempotent and performs a best-effort authenticated unregister.
- [x] Stop is terminal and bounded independently of pending direct-service
  calls; late completions cannot revive or rejoin the client.
- [x] Status, registration, and heartbeat results fail closed on unsupported
  protocol, participant type, participant identity, or canonical scope.
- [x] No secret-bearing field crosses the client status surface.
