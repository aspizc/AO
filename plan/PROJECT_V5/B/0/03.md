## Problem

Teams currently use coordination messages both as wake-ups and as durable
decisions. Ephemeral delivery is unsuitable as decision evidence, while
artifact polling alone provides no timely notification.

## Scope

- Define a versioned notice envelope that points to a newly created decision
  artifact by ID and digest.
- Treat coordination events as notices/wake-ups/pointers and artifacts as
  append-only-at-the-Gateway-API evidence.
- Specify receiver digest verification and idempotent consumption keyed by
  message/artifact identity.

## Non-scope

- No WORM/cryptographic-immutability claim, message-carried authority, or raw
  decision body in coordination metadata/audit.

## TDD RED

Reject missing/unknown artifact IDs, digest mismatches, mutable evidence,
replayed changed envelopes, cross-trace pointers, and decisions embedded only
in a message body.

## TDD GREEN

Add the strict envelope/schema, artifact lookup/projection integration, digest
verification, and durable consume receipt without changing transport ACK
semantics.

## Acceptance criteria

- [ ] Every decision notice resolves to matching server-owned evidence.
- [ ] Exact duplicate delivery is a no-op; changed replay fails closed.
- [ ] Transport ACK and semantic decision acknowledgment remain distinct.
- [ ] Coordination event/audit records remain body-free.

## Verification

Run focused notice-schema, artifact-lineage, idempotency, audit-leak, and
coordination send/receive tests; then `bash scripts/ci.sh` and
`git diff --check`.
