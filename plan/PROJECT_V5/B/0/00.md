## Problem

Valid `capabilities` and leases up to five minutes work, but an over-limit
`leaseTtlMs` collapses into an opaque `COORDINATION_INVALID_INPUT`. The
30-second default is also too short for an orchestrator reasoning turn.

## Scope

- Publish and enforce a 15-minute default and one-hour maximum, while honoring
  explicit safe configuration overrides.
- Return field-specific, non-secret validation messages and advertise the same
  integer bounds in the MCP schema.
- Preserve the distinction between `COORDINATION_INVALID_INPUT` and
  `COORDINATION_UNAVAILABLE`.

## Non-scope

- No Redis key, Lua, `agents:events`, or legacy `message.*` semantic change.
- No shared MCP restart/reconnect and no credential/config-local mutation.
