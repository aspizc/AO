Status: **complete**

Depends on: E2/S00 and E1/S02.

## Goal

Register, renew, and remove exactly one fenced lease while maintaining registry,
inbox lifecycle, and body-free metadata.

## Write scope

- participant Lua and adapter methods
- focused presence/event tests

## RED

creation failures, or body/token/digest event fields are possible.

## GREEN

NX register and digest/scope-fenced XX heartbeat/delete are atomic; stale
registry cleanup and inbox orphan TTL renewal are deterministic; events use a
strict metadata allowlist.
