## Objective

Implement the separately injected session-port issuer, immutable capability surface, FIFO
admission state machine, and the exact authenticated `ASP1` request/response codec frozen in
[`D/0/07`](07.md). This leaf establishes authority and a testable private channel seam; it does
not allocate a PTY, start a relay, or compose the real host path.

The implementation remains behind
`createProcessSupervisorSessionPortFactory(options)`. The existing
`createProcessSupervisor(...)` export and the ordinary seven-key execution object at
`gateway/src/adapters/process_supervisor.js:833-841,1270-1281` remain unchanged. Raw prompt
and snapshot bytes use only the private binary sideband; the existing bounded lifecycle JSON
encoder/parser at `gateway/src/adapters/process_supervisor.js:365-375,662-729` remains
provider-data-free.

## Scope

- Add the exact factory/issuer/claim/port/observation shapes and `WeakMap` receiver authority
  frozen in the parent.
- Enforce same-factory persistent execution claims, idempotent claim, one capability per
  execution, immutable results, argument validation, FIFO sequence allocation, and
  `BOOTSTRAPPING → ACTIVE → REVOKING → REVOKED → SETTLED`.
- Encode and decode the exact 48-byte big-endian `ASP1` header, numeric opcodes, success/error
  payloads, error/phase ids, strict sequence progression, and terminal dispositions in the
  parent codec tables.
- Construct the 32-byte binding tag exactly as the parent specifies and compare it only with
  constant-time primitives.
- Supply a construction-time `sessionPortOps` fake transport seam. It is private to the
  factory and is unreachable from requests, executions, issued values, prototypes, or errors.
- Discard provider-bearing operation buffers at settlement and retain only the revoked
  provider-free tombstone.

## Non-scope

- No PTY allocation, `setsid`, controlling terminal, foreground identity reader, terminal
  write, tmux process, relay socket, snapshot capture, adapter/service splice, or public API
  change.
- No shell, tmux `send-keys`, dependency, manifest, lockfile, policy, migration, or schema
  change.
- No claim that the real helper accepts the channel until `D/0/07b–d` are independently
  reviewed.

## Leaf boundary

This leaf produces one private, reviewed boundary for `D/0/07b`:

```text
issued JS port
  -> strict FIFO request {opcode, sequence, payload, bindingTag}
  -> injected/private sessionPortOps exchange
  <- strict response {opcode, sequence, payload, bindingTag}
```

The boundary does not expose an fd, descriptor, tag, nonce, target, token, or arbitrary byte
method. `D/0/07b` may replace only the private transport implementation with the reviewed
helper/PTY endpoint; it may not change the API or codec.

> `separately issues a persistent session port and round-trips one authenticated ASP1 request`

It starts a persistent execution through a scripted provider-data-free lifecycle fake, claims

```js
assert.equal(typeof createProcessSupervisorSessionPortFactory, "function");

assert.equal(fakeSideband.requests[0].opcode, 0x01);
assert.equal(fakeSideband.requests[0].sequence, 1);
```
