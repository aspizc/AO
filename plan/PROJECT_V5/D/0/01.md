## Problem

Blocking or shell-mediated child execution prevents concurrency, weakens
argument boundaries, and conflates transport timeout with process/session
failure. Adapter-local defaulting can also make the launched and audited
model/effort/tier differ from H/0/00's policy-resolved selection.

## Scope

- Implement an argv-array asynchronous supervisor with streaming backpressure,
  explicit cancellation, budgets, process groups, and deterministic cleanup;
  a one-shot timeout terminates and reaps the complete descendant tree.
- Own and replace every synchronous process boundary introduced during the
  historical C/1/00 Trial 1–15 line: FIFO creation, guardian/reaper topology,
  configured Python runtime resolution, no-shell `execve` entry, absolute
  deadlines, PGID/SID identity, abrupt caller/supervisor death, descendant
  adoption/reaping, and bounded exact cleanup.
- Reserve lifecycle state before spawn and reconcile exit/cancel exactly once.
- Bind supervised identity to PID, process-start token, executable/argv, cwd,
  and adapter session; verify the expected CLI is still foreground before every
  interactive control write.
- Accept only H/0/00's immutable `EffectiveAgentSelection`; the base adapter
  rejects raw/unresolved model fields. Validate the selection and provider
  support before child creation, then persist the exact effective canonical
  model, nullable effort/tier, resolution source, registry digest, and argv
  digest in the policy/audit launch record.
- Enforce exact argv parity for one-shot delegate and persistent spawn:

  | Provider | Delegate argv | Spawn argv |
  |---|---|---|
  | `codex` | `codex exec -m <model> -c model_reasoning_effort="<effort>" -c service_tier="<tier>" ...` | `codex -m <model> -c model_reasoning_effort="<effort>" -c service_tier="<tier>" ...` |
  | `claude-code` | `claude --print --output-format json --permission-mode dontAsk --no-session-persistence --model <model> --effort <effort> ...` | `claude --model <model> --effort <effort> ...` |
  | registry-only/unknown | no argv; fail closed before supervisor or child creation | no argv; fail closed before supervisor or child creation |

  Each displayed token is one argv element, never a shell fragment.
  Codex mappings are exactly `-m`, `model_reasoning_effort`, and
  `service_tier`; Claude mappings are exactly `--model` and `--effort`.
  `serviceTier` is never translated for Claude; a non-null value has already
  failed H/0/00 resolution.
- Keep policy, approval, audit, health, and cancellation calls concurrently
  responsive with explicit latency bounds while agents run or stream output.
- Remove the shell-based control channel; persistent supervised sessions have
  no automatic reasoning deadline.

## Acceptance criteria

- [ ] No adapter invokes a shell for model-agent execution/control.
- [ ] Codex and Claude delegate/spawn argv exactly match the provider matrix
      for every allowed model/effort/tier combination.
- [ ] Captured argv, dry-run, policy decision, and audit record contain the
      same canonical `EffectiveAgentSelection` values and registry digest.
- [ ] Unknown/unsupported provider, model, effort, or tier fails before the
      supervisor and child creation; no adapter supplies a local default.
- [ ] Cancellation is explicit, observable, and idempotent.
- [ ] Control input is refused unless the bound CLI instance is still foreground.
- [ ] One-shot timeout/cancel kills and reaps the complete process tree.
- [ ] Output backpressure cannot block unrelated MCP calls.
- [ ] Policy and approval remain responsive within their concurrency bound.
- [ ] Transport errors do not cause duplicate effective sessions.
