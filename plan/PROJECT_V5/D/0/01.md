## Problem

Blocking or shell-mediated child execution prevents concurrency, weakens
argument boundaries, and conflates transport timeout with process/session
failure.

## Scope

- Implement an argv-array asynchronous supervisor with streaming backpressure,
  explicit cancellation, budgets, process groups, and deterministic cleanup;
  a one-shot timeout terminates and reaps the complete descendant tree.
- Reserve lifecycle state before spawn and reconcile exit/cancel exactly once.
- Bind supervised identity to PID, process-start token, executable/argv, cwd,
  and adapter session; verify the expected CLI is still foreground before every
  interactive control write.
- Keep policy, approval, audit, health, and cancellation calls concurrently
  responsive with explicit latency bounds while agents run or stream output.
- Remove the shell-based control channel; persistent supervised sessions have
  no automatic reasoning deadline.

## Non-scope

- No command string interpolation, silent retry/duplicate launch, or transport
  timeout that marks a persistent session failed.

## TDD RED

Cover event-loop and concurrent policy/approval responsiveness, large output,
abort/exit races, foreground process replacement/death, one-shot timeout child
tree cleanup, budget exhaustion, no-shell canaries, dry-run no-child, and MCP
concurrency.

## TDD GREEN

Add one supervisor abstraction and migrate adapters/services through it while
preserving explicit one-shot vs persistent-session semantics.

## Acceptance criteria

- [ ] No adapter invokes a shell for model-agent execution/control.
- [ ] Cancellation is explicit, observable, and idempotent.
- [ ] Control input is refused unless the bound CLI instance is still foreground.
- [ ] One-shot timeout/cancel kills and reaps the complete process tree.
- [ ] Output backpressure cannot block unrelated MCP calls.
- [ ] Policy and approval remain responsive within their concurrency bound.
- [ ] Transport errors do not cause duplicate effective sessions.

## Verification

Run supervisor, foreground-identity, adapter parity, policy/approval
concurrency, timeout/cancel, lifecycle, and descendant cleanup tests; then
`bash scripts/ci.sh` and `git diff --check`.
