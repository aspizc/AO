## Problem

Process supervision alone does not stop a child from reading control state,
credentials, audit/artifacts, another task, or returning raw restricted output
through MCP.

## Scope

- Add a capability-probed sandbox backend with per-task mounts, private
  runtime/cache, minimal environment, network/egress policy, and role-specific
  read/write access.
- Route stdout/stderr and result files into private sinks and return only
  structured allowlisted status/artifact references.
- For restricted inputs, project only server-owned enums, IDs, counts, digests,
  and pre-approved requirement/risk identifiers; no returned free text may be
  derived from source, diff, prompt, stdout/stderr, or model output.
- Preserve classification unless an explicit authorized, digest-bound
  declassification decision applies; regex redaction or “no match” can never
  downgrade restricted data.
- Fail closed for restricted real execution when required isolation is absent.

## Non-scope

- No claim that same-UID directory permissions alone are isolation, regex-based
  classification downgrade, source-derived restricted summary, or raw output
  fallback for debugging.

## TDD RED

Use filesystem/env/network/output canaries for control DB, tokens, excluded
paths, cross-task data, reviewer write, symlink/mount escape, and hostile error
objects; add encoded/snippet/free-text projections and regex no-match
declassification attempts.

## TDD GREEN

Implement the isolation/mount/env/output abstractions and apply them uniformly
to headless and persistent adapters.

## Acceptance criteria

- [ ] Children cannot read operator/control secrets or unrelated task state.
- [ ] Reviewer/source write permissions match the declared role.
- [ ] Raw prompt/diff/stdout/stderr never crosses public MCP/audit surfaces.
- [ ] Restricted projections contain no source-derived text in any field.
- [ ] Sanitization alone never lowers classification or grants reviewer access.
- [ ] Missing isolation blocks restricted real mode.

## Verification

Run sandbox and restricted-projector contracts, real-canary lanes across
supported adapters/modes, declassification/egress/audit leak tests,
`bash scripts/ci.sh`, and `git diff --check`.
