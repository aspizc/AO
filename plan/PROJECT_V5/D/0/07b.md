## Objective

Replace the `D/0/07a` fake transport with a helper-owned POSIX PTY endpoint that launches the
literal provider by direct `execve`, verifies the exact live process/terminal/foreground
identity before every kernel write, and implements the parent’s mutually exclusive write
settlement intervals.

The current helper closes utility fd 0 and executes the literal argv at
`gateway/src/adapters/process_supervisor_helper.py:535-585`; this leaf changes the persistent
port path only. The one-shot path and ordinary stream behavior remain unchanged.

## Scope

- Allocate one inner PTY, retain the slave identity, set exactly 120×40, and make the
  persistent utility a session/process-group leader with that slave as controlling terminal
  and fd 0/1/2.
- Preserve literal
  `execve(launch["argv"][0], launch["argv"], launch["env"])`; never join or reinterpret argv.
- Extend the existing Linux identity reader at
  `gateway/src/adapters/process_supervisor.js:183-217` and helper Linux/Darwin readers at
  `gateway/src/adapters/process_supervisor_helper.py:75-170` with the exact executable, argv,
  cwd, PTY, winsize, and foreground evidence frozen in the parent.
- Validate the complete foreground equation before the first write and again after every
  `EINTR`, `EAGAIN`, or positive short write.
- Write only the exact strict-UTF-8 prompt plus one `0d` byte. Implement the exact
  cancel/change/close/helper-loss intervals and return no false success after an unverified
  response.
- Revoke and retire the PTY/channel before ordinary public completion settles.
- Supply a fake presentation sink for `D/0/07b`; the authenticated tmux relay is owned only by
  `D/0/07c`.

## Non-scope

- No tmux session, relay socket, peer handshake, pane capture, snapshot canonicalization,
  adapter/service/catalog wiring, or public contract change.
- No general terminal API, resize method, history API, arbitrary input, retry of an aborted
  prompt, shell, or tmux `send-keys`.
- No new native/npm dependency; Python standard library and the configured runtime only.

## Leaf boundary

`D/0/07b` consumes the reviewed `ASP1` decoder and produces this private broker seam for
`D/0/07c`:

```text
verified FIFO operation
  -> retained PTY master write / PTY slave identity
  <- streaming UTF-8-normalized terminal chunks
  -> provider-free operation result or fixed error
```

The seam exposes no caller-selected descriptor or target. `D/0/07c` may attach only the
reviewed presentation relay and snapshot barrier; it may not weaken the verified write checks.

## Acceptance criteria

- [ ] The named real-helper PTY transaction is RED after `D/0/07a` and GREEN in this leaf.
- [ ] The provider is a session/process-group leader on the retained 120×40 controlling PTY,
      and literal argv reaches direct `execve` unchanged.
- [ ] Linux and Darwin readers, exact NUL-delimited argv/cwd/executable checks, PTY inode/device,
      winsize, helper binding, and foreground equation match the parent.
- [ ] Every first write, `EINTR`, `EAGAIN`, and positive short write is preceded by a complete
      fresh identity/foreground/cancel check.
- [ ] Pre-write identity, foreground, terminal, and close failures write zero bytes and return
      their one exact error.
- [ ] A partial or full terminal write without an authenticated success response returns
      `SESSION_PORT_WRITE_ABORTED`; it is never retried or reported accepted.
- [ ] All write/cancel/exit/change/close/helper/control orderings use the mutually exclusive
      parent intervals and settle once.
- [ ] Prompt bounds, Unicode rules, CR framing, FIFO sequences, revocation order, and stale
      behavior match the shared contract.
- [ ] Raw terminal/prompt bytes stay off lifecycle JSON, transcript, audit, log, readiness, and
      public error paths.
- [ ] One-shot streams and existing supervisor tests remain unchanged; no tmux/relay code lands.
