## Problem

Independent timeouts and per-tool limits do not prevent concurrent callers or
children from exhausting processes, memory, output, disk, or provider spend.
Because those effects begin at launch and can take down policy/approval control,
the shared admission gate is a P0 prerequisite for any real-agent execution.

## Scope

- Define server-owned global and principal/repository/trace budgets for active
  processes/sessions, concurrent calls, output/artifact/audit bytes, runtime
  disk, provider requests/tokens, and configured monetary cost.
- Reserve capacity atomically before launch/effect, meter streaming usage, and
  release or reconcile reservations after exit, cancellation, crash, or boot.
- Apply hard limits and bounded backpressure uniformly to every adapter and
  execution mode; caller fields, roles, env, and YOLO grants cannot increase
  them.
- Return structured overload/budget outcomes with safe counters and retry
  guidance while policy, approval, cancellation, audit, and health remain
  responsive.

## Non-scope

- No billing-accuracy guarantee, raw prompts/provider responses in accounting,
  unlimited emergency mode, or destructive cleanup of diagnostic state.

## TDD RED

Race reservations at every scope, flood output/artifacts/audit and disk, exceed
provider request/token/cost caps, use unknown pricing, crash with held capacity,
and verify control calls remain responsive under saturation.

## TDD GREEN

Add a transactional admission/budget ledger, streaming meters, provider usage
normalization, reconciliation hooks, and bounded overload responses.

## Acceptance criteria

- [ ] Concurrent reservations cannot oversubscribe any hard global limit.
- [ ] Exhaustion rejects before child/provider work whenever it is predictable.
- [ ] Streaming overage cancels the full operation tree and records one outcome.
- [ ] Crash/restart restores accurate capacity without forgiving consumed cost.
- [ ] Budget telemetry contains only allowlisted metadata.

## Verification

Run atomic-admission races, output/disk/provider flood fixtures, crash/reconcile
and control-responsiveness tests across adapters/modes; then
`bash scripts/ci.sh` and `git diff --check`.
