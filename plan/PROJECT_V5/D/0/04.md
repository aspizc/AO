## Problem

Layer-local tests do not prove the external MCP boundary resists identity
spoofing, process/control races, filesystem escape, and raw-data egress
together.

## Scope

- Build adversarial external-server E2E for principal/repo/trace replay,
  sandbox/process races, single-writer recovery, artifact/output/audit canaries,
  and denied authority paths.
- Drive the complete sequence through one external Gateway and one persistent
  MCP connection, including overlapped requests, a blocked wait, policy/
  approval status, cancellation, reconnect semantics, and shutdown cleanup.
- Require both dry-run and isolated synthetic real-mode fixtures.
- Gate real execution expansion on explicit no-skip and coverage thresholds.

## Non-scope

- No attack against shared/live infrastructure, real secret corpus, destructive
  stress/DoS, or self-issued approval.

## TDD RED

Each exploit fixture must demonstrate a failing pre-fix condition or an
independently validated guard; a helper that starts a Gateway/connection per
tool call, or any missing server/capability/fixture, fails the lane.

## TDD GREEN

Integrate isolated fixtures, bounded fault hooks, canary scanner, coverage
accounting, and deterministic cleanup.

## Acceptance criteria

- [ ] Actor/repo/trace/task spoof and replay cannot reach side effects.
- [ ] Child escape/control-channel/raw-egress canaries remain inaccessible.
- [ ] Crash/restart leaves one writer and one effective operation.
- [ ] One persistent connection proves sequence, overlap, wait, cancel, and cleanup.
- [ ] No test helper creates a Gateway process per tool call.
- [ ] The gate cannot pass via mock-only, skip, or zero-test execution.

## Verification

Run the persistent-connection adversarial lane on a clean disposable
repository/runtime twice, overlap/cancel/shutdown leak checks, full Gateway/E2E
suites, `bash scripts/ci.sh`, and `git diff --check`.
