## Objective

Connect the reviewed broker/PTY seam to one exact tmux relay instance, authenticate that
instance with kernel peer identity plus a single-use nonce proof on Linux and Darwin, render the
fixed pane without `send-keys`, and return byte-deterministic canonical snapshots.

Tmux remains only the outer presentation pane. It never launches the provider. The public
identity remains `sessionId === tmuxTarget` with literal
`tmux attach -t <tmuxTarget>`, matching
`gateway/src/services/agent_service.js:380-390` and
`gateway/src/tools/session.js:5-17`.

## Scope

- Create the private 0700 runtime directory, 0600 Unix socket, single-use relay-key file, and
  exact `ASR1` authenticated handshake frozen in the parent.
- Launch the configured-runtime relay through tmux direct multi-argument mode only; reject a
  runtime/tmux without that capability and never fall back to a shell.
- Bind the accepted socket to the exact tmux pane PID/start/executable/argv/cwd plus Linux
  `SO_PEERCRED` or Darwin `getpeereid` + `LOCAL_PEERPID`, then verify the challenge proof in
  constant time before polling relay stdin.
- Forward normalized PTY output with bounded backpressure and serialize post-handshake operator
  input through the broker queue. Operator attach remains separate local R/W authority.
- Implement relay flush barriers, fixed 120×40 pane/400-line history checks, the exact direct
  capture arguments `["capture-pane","-p","-N","-T","-t",tmuxTarget,"-S","-400"]`, the parent
  canonicalization algorithm, UTF-8/ANSI behavior, cap, and oldest-prefix truncation.
- Revoke on relay/socket/pane/tmux replacement or any handshake/capture invariant failure.
- Seal separate cleanup-ledger targets for component-owned retained descriptors, the one-time
  relay key, relay socket pathname, runtime directory, exact process targets, and port-owned
  pane/session. Apply the ratified Decision 4C `RETIRED`/`PRESERVED` outcomes without treating
  pathname presence as descriptor liveness.

## Non-scope

- No capability/API/codec change from `D/0/07a`, no weakening of `D/0/07b` writes, no provider
  launch through tmux, no adapter/service/catalog splice, and no public attach endpoint.
- No shell, `send-keys`, `capture-pane -e`, `-J`, resize API, arbitrary history API, or raw ANSI
  return.
- No full real-host composition/race release gate; `D/0/07d` owns that final proof.
- No post-`V` product `unlink`/`rmdir`, shared tmux server/socket cleanup, production janitor,
  namespace-retention period, basename-reuse protocol, or deletion policy. Isolated harness
  teardown is external evidence hygiene only.

## Leaf boundary

This leaf consumes normalized terminal chunks and the verified operator-input queue from
`D/0/07b`. It produces:

```text
authenticated exact relay instance
  + fixed tmux server/session/pane identity
  + barriered canonical snapshot bytes
  + inert {sessionId, tmuxTarget, attachCommand}
  + sealed cleanup targets with terminal RETIRED/PRESERVED outcomes
```

`D/0/07d` may compose those reviewed values with the issuer and real helper lifecycle, but may
not redefine the handshake, canonicalizer, attach identity, or snapshot DTO.
