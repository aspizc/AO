# C/1/02 — Honest `orchestration.complete` preflight and typed blockers

| Field | Value |
|---|---|
| Status | `planned` |
| Functional priority | P0 — prevent false completion |
| Depends on | `C/1/01` |
| absorbed_from | V4 `B/1/03` (V4 specification provenance; behavior not yet implemented) |
| Review id | `C_1_2` |

## Problem

Completion may be accepted while work is still starting/running, approval is
pending, recovery is required, or evidence/review is missing.

## Scope

- Run completion through an atomic server-side preflight over the normalized
  overview and lifecycle version.
- Return stable typed blockers with affected IDs and recovery actions.
- Complete only when the same observed state version still satisfies every
  applicable gate.

## Non-scope

- No automatic approval, risk waiver, task cancellation, review synthesis, or
  “best effort” terminal state.

## TDD RED

Attempt completion with every nonterminal session/task, pending/expired
approval, stale/missing gate, orphan/reconcile flag, state-change race, and an
unknown blocker type.

## TDD GREEN

Add a typed blocker evaluator and compare-and-transition completion command
backed by the lifecycle reducer.

## Acceptance criteria

- [ ] Completion is atomic against the evaluated lifecycle version.
- [ ] Every denial returns actionable, typed, non-secret blockers.
- [ ] No caller flag bypasses a blocker.
- [ ] A completed trace has no open work or applicable unmet gate.

## Verification

Run completion preflight/race/tool tests and lifecycle regression suites; then
`bash scripts/ci.sh` and `git diff --check`.
