## Problem

Unit reducer tests do not prove that the public MCP surface remains honest
through disconnects, crashes, stale callers, and restart reconciliation.

## Scope

- Exercise create/start/observe/recover/complete over an external MCP server and
  disposable state.
- Inject failures at reserve/launch/persist/terminal boundaries and restart the
  test server.
- Assert overview/blocker truth and exactly-once effective transitions.

## Non-scope

- No shared MCP/Redis process, real model spend, repository push, or synthetic
  success when the subprocess/service is unavailable.

## TDD RED

Show premature completion, duplicate launch after transport loss, stale
terminal retry, and orphaned `starting` currently escape or remain ambiguous.

## TDD GREEN

Add deterministic fault hooks, restart harness, reconciliation entry point, and
MCP assertions for every public lifecycle state.

## Acceptance criteria

- [ ] False completion is denied before and after restart.
- [ ] Recovery converges without duplicate effective launch/terminal event.
- [ ] Overview explains injected orphan/race states.
- [ ] Required E2E fails on skip, zero tests, or missing external server.

## Verification

Run the recovery E2E twice with distinct disposable state, all lifecycle/tool
tests, `bash scripts/ci.sh`, and `git diff --check`.
