## Problem

There is no canonical answer to “what is still open on this trace?” across
tasks, sessions, approvals, reviews, and recovery blockers.

## Scope

- Add a normalized, allowlisted trace overview projecting task/session states,
  pending approvals, review requirements, current blockers, and recovery hints.
- Derive it server-side from authoritative repositories at one consistent
  observation boundary.
- Expose stable direct and MCP shapes suitable for CLI consumption.

## Non-scope

- No raw prompts/output/diffs, generic database query, hidden mutation, or
  approval decision from the overview.

## TDD RED

Cover empty/mixed traces, multiple sessions, pending/expired approvals,
missing/stale review, orphaned starting state, cross-trace contamination, and
secret/raw projection canaries.

## TDD GREEN

Implement a typed query/projection service with deterministic ordering and a
registered read-only tool.

## Acceptance criteria

- [ ] One call explains all open work and typed blockers for a trace.
- [ ] Projection is deterministic, bounded, and free of raw agent content.
- [ ] Cross-trace records can never appear.
- [ ] Missing/corrupt optional records degrade explicitly, not as “complete”.

## Verification

Run trace-overview repository/service/tool tests, projection leak canaries, and
schema parity; then `bash scripts/ci.sh` and `git diff --check`.
