## Problem

The operator lacks a trusted, live inventory of orchestrations, tasks, sessions,
process health, and recovery state without querying internal storage.

## Scope

- Add a versioned local operator control transport with peer checks and bounded
  read-only `list`, `show`, and `status`.
- Project normalized overview/lifecycle/process state through strict allowlists.
- Include active/nonterminal work and a cursor-paginated, time/count-bounded
  recent terminal history with deterministic ordering and retention semantics.
- Let an authenticated operator start with no trace/task/session IDs and
  reconstruct the server-owned orchestration → task → session relationships
  needed for inspection, cancellation, or recovery.
- Keep the transport outside agent mounts and separate from public MCP.

## Non-scope

- No mutation, arbitrary query, unbounded terminal archive, raw prompt/output/
  diff, direct database access, or network listener in this sheet.

- [ ] Operator can enumerate and inspect every live/nonterminal orchestration.
- [ ] From zero known IDs, recent bounded history recovers trace/task/session IDs.
- [ ] Status distinguishes healthy, degraded, blocked, and recovery-required.
- [ ] Agents cannot access the operator transport.
- [ ] No control-store schema/raw payload leaks through responses.
