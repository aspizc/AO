## Problem

Review artifacts can be treated as current after the change digest moves, and
informal “OK” may bypass missing tests, dispositions, independence, or approval.

## Scope

- Add a review state reducer bound to manifest/evidence digest and version.
- Invalidate stale reviewer/test evidence automatically.
- Evaluate an exact gate requiring approved plan, tests, A, independent B,
  exhaustive dispositions, and zero unresolved blockers; model risk acceptance
  as a separate signed approval.

## Non-scope

- No free-text verdict parser, implicit risk waiver, stale evidence reuse, or
  reviewer self-approval.

## TDD RED

Change each digest/input after evidence, omit/duplicate a concern/disposition,
inject failed/unknown tests, same reviewer, open blocker, replay grant, and race
two gate evaluations.

## TDD GREEN

Implement reducer/repository, invalidation triggers, deterministic evaluator,
and immutable gate-result artifact.

## Acceptance criteria

- [ ] Any relevant digest/version change invalidates prior evidence.
- [ ] Gate reason codes enumerate every unmet condition.
- [ ] Gate success is deterministic and evidence-bound.
- [ ] Risk acceptance requires its own exact signed operator decision.

## Verification

Run reducer transition/staleness/gate matrix and approval-binding tests; then
`bash scripts/ci.sh` and `git diff --check`.
