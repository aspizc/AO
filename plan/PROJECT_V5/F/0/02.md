## Problem

A single conversational review cannot independently cover requirements/risks
and inspect real source while preserving restricted-data boundaries.

## Scope

- Run Reviewer A over approved requirements plus deterministic safe manifest
  projection, with no source mount.
- Run independent Reviewer B over the exact manifest digest and read-only source
  mount, disposing every A concern and its own findings in structured form.
- Enforce model/session independence or an explicit operator-bound waiver.

## Non-scope

- Reviewer A cannot approve code; Reviewer B cannot write source, grant
  approval, or return raw source/diff through MCP.

## TDD RED

Test A source canary, B write canary, prompt-injected concerns, stale digest,
missing/duplicate dispositions, open blocking finding, same-agent selection,
and scratch/cache crossover.

## TDD GREEN

Add reviewer roles/launchers, typed concern/disposition schemas, isolated mounts,
independence selector, and evidence artifacts.

## Acceptance criteria

- [ ] A covers requirements/risks without source access.
- [ ] B inspects the exact source and cannot mutate it.
- [ ] Every A/B concern has exactly one structured disposition/evidence link.
- [ ] Reviewer identity/session is independent or explicitly waived.

## Verification

Run reviewer schema/selector/isolation/canary tests and synthetic dual-review
integration on both supported model orders; then `bash scripts/ci.sh` and
`git diff --check`.
