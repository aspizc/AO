# W/0/2 - Task-less session E2E and docs

## Quick reference

| Campo | Valor |
|---|---|
| Stage | W - Task-less sessions |
| Branch | `feature/W-0-2-taskless-session-e2e-docs` |
| Depende de | W/0/1, U/0/5 |
| Esfuerzo | S-M (2-4h) |

## Por que existe?

W/0/0 y W/0/1 habilitan la funcionalidad. Esta tarea evita regresiones y aclara
al operador cuando usar sesiones sin task y cuando mantener el flujo trazable
con `task.assign`.

## Que hay que hacer?

Anadir E2E MCP dry-run para sesiones sin task y actualizar documentacion
operativa.

## Plan de implementacion paso a paso

### 1. Branch

```bash
git checkout develop && git pull --ff-only || true
git checkout -b feature/W-0-2-taskless-session-e2e-docs
```

### 2. E2E MCP

Crear `tests/e2e/mcp_taskless_session.test.js` o extender el helper MCP de
K/0/4:

1. Arrancar Gateway MCP con `AGENTS_DRY_RUN=1`.
2. Crear `orchestration.create` para obtener `traceId`.
3. Llamar `agent.spawn` sin `taskId` en repo permitido.
4. Ejecutar `agent.ask`, `agent.view`, `session.attach_info`, `agent.kill`.
5. Verificar audit y SQLite:
   - hay `SESSION_STARTED`;
   - `taskId` es null;
   - `taskLinked` es false;
   - no hay `TASK_CREATED` requerido para esa sesion.

### 3. Docs

Actualizar:

- `docs/operator-guide.md`
  - seccion "Task-linked sessions" como camino recomendado;
  - seccion "Task-less sessions" para exploracion controlada;
  - advertencia: no usar task-less para trabajo que deba cerrarse contra una
    task/review formal.
- `README.md`
  - resumen breve de ambos modos.
- `docs/mvp-acceptance-checklist.md`
  - nota de que task-less es extension Stage W, no requisito MVP restricted.

### 4. CI

Si `scripts/ci.sh` ya corre todos los E2E, no tocarlo. Si no, incluir el nuevo
test explicitamente.

## Errores comunes

- Presentar task-less como reemplazo de `task.assign`.
- No verificar audit.
- Probar con services internos en vez de MCP stdio.
- Requerir CLIs reales o red.
