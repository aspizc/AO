## Por que existe?

`orchestrator-langgraph/` tiene ~2.6k lineas de codigo y 13+ ficheros de test,
pero `scripts/ci.sh` no los ejecuta nunca (hallazgo A1, High). Cualquier
cambio puede romper ese subproyecto sin deteccion. Es la primera pieza de la
red de seguridad: sin esto, B/0/1 (refactor de manejo de errores en 5 flujos
Python) seria exactamente la regresion silenciosa que la auditoria advierte.

## Que hay que hacer?

Anadir una seccion al gate local que ejecute `pytest` sobre
`orchestrator-langgraph/tests`, respetando los skips defensivos ya existentes
(`pytest.importorskip("temporalio...")`, gates `AGENTS_TEMPORAL_INTEGRATION`).

## Plan de implementacion paso a paso

### 1. Branch

```bash
git checkout develop && git pull --ff-only || true
git checkout -b feature/V3-A-0-0-full-ci-gate
```

### 2. Seccion nueva en `scripts/ci.sh`

Insertar tras la seccion "CLI tests (pytest)" (mantener el estilo de las
secciones existentes, `echo "==> ..."`):

```bash
echo "==> Orchestrator LangGraph tests (pytest)"
pytest orchestrator-langgraph/tests
```

Los tests que requieren `temporalio`/`langgraph`/`redis` ya se auto-skipean
si la dependencia no esta instalada; el gate no debe exigir Temporal real
(eso sigue siendo opt-in via `AGENTS_TEMPORAL_INTEGRATION=1`).

### 3. Setup documentado

Actualizar el Quickstart de `README.md` para que el venv instale tambien el
subproyecto: `pip install -e "orchestrator-langgraph"` (o documentar que sin
instalarlo los tests se skipean — elegir lo primero: el gate debe ejecutar
los tests de verdad, no skipearlos en bloque). Verificar que
`orchestrator-langgraph/pyproject.toml` ya configura
`pythonpath = ["src"]` para pytest (lo hace).

### 4. Verificacion local

```bash
./scripts/ci.sh                       # verde con la nueva seccion
pytest orchestrator-langgraph/tests  # mismo resultado standalone
```

Romper temporalmente un assert de
`orchestrator-langgraph/tests/test_selector.py`, comprobar que `ci.sh` falla,
y revertir.

## Detalle adicional de ejecucion

- El `ci.sh` actual termina tras `pytest tests/cli`; la nueva seccion debe
  quedar antes de `echo "==> All checks passed."`.
- Usar `pytest orchestrator-langgraph/tests` dentro del mismo venv que aporta
  `agent-run`. Si falta una dependencia del subproyecto, no marcar la suite
  entera como opcional: corregir la instalacion documentada o declarar el
  bloqueo en la review.
- Ampliar preferentemente `tests/structure/test_ci_script.py` en vez de crear
  otro structure-test duplicado.
- En la review, incluir el resultado de `pytest orchestrator-langgraph/tests`
  y de `./scripts/ci.sh`, mas la prueba manual de fallo con assert roto.
- No instalar Temporal/Postgres/Redis para esta tarea: los tests reales siguen
  controlados por sus propios gates opt-in.

## Errores comunes

- ❌ Anadir la seccion con `|| true` o como paso opcional: el objetivo es que
  FALLE el gate cuando el subproyecto se rompe.
- ❌ Exigir `temporalio`/Temporal server en el gate: la integracion real sigue
  siendo opt-in.
- ❌ Tocar los tests del subproyecto para "hacerlos pasar": si algo esta rojo
  hoy, se documenta y se abre KO antes de mergear.
