## Por que existe?

El README contradice el codigo: declara fuera de alcance "Postgres, Redis
Streams, event bus, LangGraph client" (`README.md:124`) cuando
`gateway/src/core/postgres_db.js` existe, `audit.js` publica a Redis Streams
y `orchestrator-langgraph/` esta en el arbol — es trabajo V1 mal comunicado,
no codigo fantasma. Ademas la tabla de env vars (`README.md:129-144`) omite
7 variables que `gateway/src/config.js` SI carga:
`AGENTS_MESSAGE_ACCESS_SECRET`, `AGENTS_MESSAGE_ACCESS_SECRET_FILE`,
`AGENTS_OTEL_ENABLED`, `AGENTS_OTEL_EXPORTER`, `AGENTS_OTEL_SERVICE_NAME`,
`AGENTS_REDIS_URL`, `AGENTS_REDIS_STREAM`. Y `docker/docker-compose.yml` es
funcional pero ninguna guia lo referencia.

## Que hay que hacer?

Corregir el README (tabla env completa + seccion "V1 experimental" +
referencia a docker-compose) y anadir un structure-test que impida que la
tabla vuelva a divergir de `config.js`.

## Detalle adicional de ejecucion

- Fuente de verdad: `gateway/src/config.js`. No documentar variables

- El parser de README debe reconocer variables escritas entre backticks en la

  pasar si encuentra cero variables; mantener un umbral minimo razonable.
