## Por que existe?

`orchestrator-langgraph/pyproject.toml:6-10` declara `langgraph`, `mcp` y
`temporalio` SIN ningun limite de version, y no existe lockfile en el repo:
un install fresco puede traer breaking changes silenciosos. Ademas `redis` se
importa en runtime (`consumers/metrics.py:158-165`) pero no esta declarado en
ningun manifest: el consumidor de metricas no es instalable de forma
reproducible.

## Que hay que hacer?

Acotar versiones en ambos `pyproject.toml`, declarar `redis` como extra
opcional, y commitear un lockfile (`uv lock`).

## Plan de implementacion paso a paso

### 1. Branch

```bash
git checkout develop && git pull --ff-only || true
git checkout -b feature/V3-C-0-0-python-pins-lockfile
```

### 2. Pins

- `orchestrator-langgraph/pyproject.toml`: fijar las versiones actualmente
  instaladas en `.venv` como base (`pip show langgraph mcp temporalio`) con
  bounds compatibles, p.ej. `langgraph>=X.Y,<X+1` (langgraph pre-1.0: acotar
  a minor). Anadir:

  ```toml
  [project.optional-dependencies]
  redis = ["redis>=5,<6"]
  ```

- `cli/pyproject.toml`: ya tiene `>=`; anadir upper bounds coherentes
  (`typer<1`, `rich<15`, `jsonschema<5`) sin cambiar minimos.

### 3. Lockfile

Usar `uv` (workspace o por-proyecto, lo que resulte mas simple — si uv
workspace complica, un `uv lock`/`requirements.lock` por subproyecto vale):

```bash
uv lock   # o: uv pip compile pyproject.toml -o requirements.lock (por proyecto)
```

Commitear el lockfile y documentar en el README/Quickstart como instalarlo
de forma reproducible. Si `uv` no esta disponible en el entorno del coder,
fallback aceptable: `pip freeze` filtrado a `requirements.lock` por
subproyecto, documentado.

### 4. Actualizar consumo de redis

`consumers/metrics.py` mantiene el import lazy (correcto para no obligar la
dependencia), pero su `RuntimeError` debe mencionar el extra:
`pip install "orchestrator-langgraph[redis]"`.

### 5. Verificacion

Venv fresco: instalar desde el lockfile y ejecutar
`pytest orchestrator-langgraph/tests` y `./scripts/ci.sh`.
