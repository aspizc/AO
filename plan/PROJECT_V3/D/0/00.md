## Por que existe?

Tres modulos del nucleo no tienen tests directos: `gateway/src/core/telemetry.js`
(228 lineas: extraccion de traceId, sanitizacion de atributos, exporters),
`gateway/src/core/trace_access.js` (tokens HMAC de acceso a mensajes) y los
caminos de error de `gateway/src/mcp_server.js` (tool desconocida, handler
que lanza, fallo de audit append). Fallos aqui degradan observabilidad o
control de acceso en silencio.

## Que hay que hacer?

Tres ficheros de test unitario directo, sin tocar produccion.

### 2. `tests/gateway/telemetry_unit.test.js`

### 4. `tests/gateway/mcp_server_errors.test.js`

Sobre `createCallToolHandler` (exportado, `mcp_server.js:59`):

- Tool desconocida → rechaza con `unknown tool <name>`; span con status
  ERROR; audit append invocado igualmente (comportamiento post-B/0/3).
- Handler que lanza → la excepcion se propaga, `span.recordException`
  llamado, `span.end()` SIEMPRE (finally).
- `append` que lanza → warning a stderr, la respuesta del tool no se ve
  afectada (`appendToolCallAudit`, :41-57).
- Resultado con `isError` y JSON en `content[0].text` → `error.code`
  extraido y truncado a 200 (`parseToolErrorCode`, :29-39); JSON invalido →
  sin crash, code undefined.

## Detalle adicional de ejecucion

- Los tests son de caracterizacion: si descubren un comportamiento raro pero
  existente, fijarlo y abrir follow-up salvo que el bug bloquee la tarea.
- Para telemetry, usar `InMemorySpanExporter` cuando baste y capturar stderr
  solo para el exporter `stderr`; no depender de timestamps exactos.
- Para `trace_access`, comprobar explicitamente que tokens de longitud
  distinta devuelven `false` antes de `timingSafeEqual`; no deben lanzar.
- Para `mcp_server`, construir fakes pequenos de span/telemetry/append y
  asertar que `span.end()` ocurre tambien cuando el handler lanza.
- Los tests de error no deben arrancar el servidor stdio real; ejercitan
  `createCallToolHandler` como unidad exportada.

- ❌ "Arreglar" comportamientos raros descubiertos: esta tarea congela; los
  fixes se abren como hallazgos.
