### Alcance

`agent-run audit show` presenta timestamp, event, action, actor role, decision,
ruleId, approval/session ID y traceId completo. Campos ausentes usan `-`; filas
corruptas no rompen el render. Cabecera explica limite/filtros. `--json`
conserva un envelope estable y allowlisted.

La proyeccion nunca imprime prompt, payload, diff, stdout/stderr, snapshot,
token o raw artifact path. Full ID no significa full payload.
