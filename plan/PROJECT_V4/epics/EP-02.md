# EP-02 — Coherencia documental y configuración local

[← Índice de épicas](README.md) · [Proyecto V4](../README.md) · [Auditoría integral](../../../audit/2026-07-26-project-wide/README.md)

> Estado actual: **ejecución autorizada; cierre pendiente de absorción V5**. Las tareas enlazadas siguen siendo las unidades canónicas y no se cierran sin evidencia.

**Propósito y outcome.** Hacer que ADRs, vista humana de modelos y ejemplo MCP
describan el producto soportado sin activar V1 ni replicar el control plane
dentro de children.

**Findings cubiertos.** `OPS-04`, `V1` soportado/experimental ambiguo,
documentación de modelos stale y configuración `.mcp.json` recursiva.

**Stages implicados.** A/0.

**Tareas y orden.**

1. [`A/0/00`](../A/0/00.md) — reconciliar ADR MVP↔V1 y declarar V1 fenced.
2. [`A/0/01`](../A/0/01.md) — `docs/models.md` como proyección del registry.
3. [`A/0/02`](../A/0/02.md) — config MCP local sin autonomía ni workspace
   solapado.

Las tres pueden ejecutarse desde sus dependencias exactas; A completa G1 sólo
cuando M0-ready ya está demostrado.

**Gates y dependencias.** `A/0/00` y `A/0/02` dependen de la base M0; `A/0/01`
depende de `M0/2/02`. Las tres son terminales de G1.

**Exit criteria.**

- V1 aparece simultáneamente como `experimental`, `opt-in` y `not supported`.
- Docs de modelos se verifican bidireccionalmente contra registry.
- `.mcp.json` local no se versiona ni se hereda por worktrees/children.
- Ningún flag/env/config fabrica `workspace-yolo` o `host-unconfined`.
- Un E2E de child demuestra cero Gateway recursivo.
