# EP-10 — Contrato V1 y convergencia Temporal

[← Índice de épicas](README.md) · [Proyecto V4](../README.md) · [Auditoría integral](../../../audit/2026-07-26-project-wide/README.md)

> Estado actual: **ejecución autorizada; cierre pendiente de absorción V5**. Las tareas enlazadas siguen siendo las unidades canónicas y no se cierran sin evidencia.

**Propósito y outcome.** Contener V1, corregir parsers fail-closed y converger
ITRP en Temporal V2 sin romper replay V1; LangGraph conserva plan-refine y deja
de ser una segunda implementación ITRP.

**Findings cubiertos.** `QA-01/02`, `V1-01…07`, Python 3.14 nominal,
`exitCode` ignorado, reviewer KO que avanza, taskId reutilizado, worker relativo
al cwd y dos ITRP divergentes.

**Stages implicados.** E/0, E/1 y E/3.

**Tareas y orden.**

1. [`E/0/00`](../E/0/00.md) — runtime fence/Python/dependency scan.
2. [`E/0/01`](../E/0/01.md) — semántica estricta de resultados.
3. [`E/0/02`](../E/0/02.md) — verdict plan-refine estricto.
4. [`E/1/00`](../E/1/00.md) — golden legacy y contrato normativo V2.
5. [`E/1/01`](../E/1/01.md) — shell V2/namespaces.
6. [`E/1/02`](../E/1/02.md) — cliente V2 sobre worker channel único.
7. [`E/1/03`](../E/1/03.md) — operation IDs durables.
8. [`E/1/04`](../E/1/04.md) — approval `change.accept` autoritativo.
9. [`E/1/05`](../E/1/05.md) — dual review sin raw en history.
10. [`E/1/06`](../E/1/06.md) — replay/crash/contrato V2.
11. [`E/1/07`](../E/1/07.md) — selector y cutover.
12. [`E/3/00`](../E/3/00.md) — retirar ITRP LangGraph.

**Gates y dependencias.** E/0 sigue G1; H0 mantiene V1 fenced. `E/1/00`
espera G6 y H0; H1 aprueba contrato, H2 approval/review, y la retirada final
espera EP-11/E/2/03 + H4.

**Exit criteria.**

- Python soportado es `>=3.11,<3.14` con matrix y timeout técnico de suite.
- Envelope Gateway real gobierna success; non-zero/ambiguo/KO bloquea antes de
  approval o push-intent.
- Plan-refine acepta sólo enum JSON.
- Histories V1 replayan en workers antiguos/nuevos.
- Worker instalado funciona fuera del checkout y usa un Gateway.
- Implement/test/review tienen task IDs/principals distintos.
- Approval liga approval/trace/action/digest/gate/expiry y se repollea.
- History no contiene diff/prompt/stdout/path/secreto.
- No existe fallback silencioso; finalmente queda un ITRP productivo.
