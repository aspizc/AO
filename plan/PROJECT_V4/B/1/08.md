## Ficha ejecutable

- **Estado:** Backlog planificado.
- **Objetivo:** garantizar un Gateway long-lived propietario de DB/audit/artifacts.
- **Scope/evidencia:** boot, workspace lock, process inventory, ADR y tests.
- **Aceptación:** lock auto-release e instance/boot ID; CLI/workers/children no escriben; MCP recursivo no abre el workspace.
- **Tests/gate:** segundo Gateway falla antes de DB; reproduce 35 procesos como negativo; lock se recupera tras muerte.
- **Dependencias:** B/1/03 y B/1/04.
- **Esfuerzo/riesgo:** ≤1 día; riesgo **crítico** por multi-writer/recovery.

## Especificación detallada

- **Dep:** B/1/03, B/1/04. **Paths:** Gateway boot/workspace lock/tests/ADR.
- **Entrega:** un Gateway long-lived posee DB/audit/artifacts; lock auto-release,
  instance/boot ID e inventario de procesos. CLI/workers/children no son writers
  y un MCP cargado recursivamente no puede abrir el mismo workspace.
- **Rojo:** segundo Gateway (incluido child host) falla stderr antes de abrir DB;
  35 procesos contra el mismo workspace se reproducen como test negativo y el
  lock se recupera tras muerte.
  **Rollback:** drenar unico Gateway; nunca dos writers.
