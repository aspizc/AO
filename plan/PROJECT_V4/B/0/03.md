## Especificación detallada

- **Dep:** B/0/02, B/1/01. **Paths:** agent service/cancel plumbing y tests MCP.
- **Entrega:** abort explicito/idempotente; transporte timeout no marca session
  spawn como fallida ni crea duplicado. Admission limita concurrencia, bytes de
  output/artifact/audit y presupuesto de proveedor por principal/repo/trace;
  overload responde estructurado sin bloquear policy/approval/audit.
- **Rojo:** call concurrente responde; cancel race una vez; reattach tras
  transport error; flood/output/coste excedido se rechaza antes del child.
  **Rollback:** bloquear nuevos one-shots.
