## Especificación detallada

- **Dep:** B/3/01, B/1/02. **Paths:** data inventory/schema, config de retention,
  ADR/runbook y contract tests; no borrado todavia.
- **Entrega:** cada dataset SQL, artifact bytes, JSONL, Redis y Temporal declara
  owner, purpose, classification, source/lineage, minimizacion, retention,
  backup, export, erase/legal-hold y procesador/residencia cuando aplique.
  Defaults locales son finitos y fail-closed; prompts/outputs no se duplican sin
  necesidad explicita.
- **Rojo:** store/campo sin owner/retention o `forever` implicito falla; docs se
  generan/verifican desde el catalogo.
- **Rollback/review:** conservar catalogo aun con sweepers off; privacy/ops
  review, sin afirmar compliance legal.
