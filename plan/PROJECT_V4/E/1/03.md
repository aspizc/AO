## Ficha ejecutable

- **Estado:** Backlog planificado.
- **Objetivo:** deduplicar side effects entre retries, crash, reset y nuevo Run.
- **Scope/evidencia:** idempotency repo/migration, activity wrappers y fault tests.
- **Aceptación:** ID deriva de workflow/logical step/business attempt/trace/action/digest; implement/test/review tienen task IDs y principals distintos.
- **Tests/gate:** crash antes de ACK y reset/new Run dejan exactamente una session/approval/review/gate/artifact.
- **Dependencias:** E/1/02.
- **Esfuerzo/riesgo:** ≤1 día; riesgo **crítico** de idempotencia/migración.
- **Fuente:** [trazabilidad V4](../../AUDIT.md), [spec/índice de stage](../TASKS.md) y [auditoría integral](../../../../audit/2026-07-26-project-wide/README.md).

## Especificación detallada

- **Dep:** E/1/02. **Paths:** idempotency repo+migration, activity wrappers,
  tests de fault.
- **Entrega:** IDs derivados de workflowId+logicalStep+businessAttempt+trace+
  action+changeSetDigest; Run ID solo metadata forense. Uniqueness/result
  persistidos para agent run, reviews, approval request, artifact put y gate.
  Workflow task padre y subtasks implement/test/review tienen IDs distintos y
  binding server-side exacto de assigned agent/role; nunca se reutiliza un
  `taskId` entre principals.
- **Rojo:** crash antes de ACK y Temporal reset/new Run dejan exactamente una
  session, approval, review, gate y artifact.
  **Rollback:** backup/restore y starts off.
