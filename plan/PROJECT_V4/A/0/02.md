### Alcance

- `/.mcp.json` en `.gitignore`; no borrar el fichero local del operador.
- `client-config/mcp.json.example` usa placeholders/rutas relativas, dry-run,
  sin `AGENTS_AUTOAPPROVE` y sin paths del owner.
- El MCP de control se habilita solo en el host/orchestrator autorizado. Child
  worktrees, Codex/Claude/Gemini y reviewers no heredan ni montan `.mcp.json`,
  settings que auto-habiliten project MCP ni credenciales/control sockets.
- Ninguna variable/config local convierte por si sola un rol en YOLO ni concede
  `workspace-yolo`/`host-unconfined`; esos modos requieren el grant firmado
  B/2/03 aunque el fichero diga `--yolo`, `danger-full-access` o equivalente.
- El ejemplo exige `AGENTS_WORKSPACE` fuera de todos los repo roots y avisa que
  esto es higiene, no aislamiento frente a procesos del mismo UID.
- Docs apuntan a B/1/07 para real mode aislado y a B/2/02 para approvals.

### TDD
